# 增强日内规则与验证协议

旧SMA、开盘突破、VWAP回归保持可用。新增两套规则可按股票分别选用，均只做多、不隔夜，信号只来自已完成分钟。

## 趋势过滤突破 `trend_breakout`

- 等待开盘15分钟和至少21根历史。突破开盘高点及近期高点较高者，缓冲0.1×ATR；前一分钟没有站上同一突破线，避免反复追价。
- 短均线高于长均线，收盘在VWAP之上；20根方向效率至少0.25，相对近期成交量至少1.2。
- 距VWAP不得超过4×ATR，减少过度延伸的追涨。
- 目标距离3×ATR，必须超过预计往返成本的1.5倍另加1bps。目标距离不是收益预测。

## 止跌确认回归 `range_reversion`

- 20根方向效率不超过0.35，倾向震荡环境。
- 收盘低于VWAP，偏离至少为30bps与2×ATR中的较大者。
- 当前收盘高于上根收盘、当前开盘，且处于当根振幅上部40%，确认初步止跌后才入场。
- 目标为VWAP距离和3×ATR中的较小者；同样必须覆盖成本缓冲。

## 共用约束（只作用于增强规则）

ATR使用最近14根真实波幅的简单平均，考虑相邻分钟缺口。当前ATR/价格须在过去最多20个已完成交易日日均振幅比例均值的0.5—3倍内；无历史时用当前ATR作为基准。每日结束后才把该日背景加入，避免用全天信息解释早盘。

入场信号时冻结止损距离：2×ATR与硬止损1%中的较小者。依据现金的25bps风险预算限制股数，再受成交量参与率和实际现金约束。成交后采用实际入场价加减冻结距离；风险预算是近似值，不含跳空、碎单费用，不能保证最大亏损。

- 止损、3×ATR目标止盈；盈利达到一份风险距离后，启用同距离的收盘峰值跟踪退出。
- 回归达到VWAP退出；突破跌破VWAP退出。
- 最长持有30根完整分钟，平仓后冷却10分钟，每股每天最多4次入场。
- 相对当日初始权益亏损达到1%时清仓，并停止当天入场；即使之后价格恢复也不重新开启。
- 距收盘不足最长持仓时间时不新开仓，保持原来收盘前5分钟清仓和部分退出锁定机制。

以上止损/止盈以**分钟收盘触发、次分钟开盘近似成交**，没有假设能按分钟内最优价格成交。原版策略仍使用原有风控。全部策略按实际模拟路径扣除成本，不能通过减低费用优化结果。

## 固定对比集合

`quant-workbench study --suite enhanced` 每股11个候选：3个旧纯规则，2个增强规则各搭配纯规则、线性5分钟成本过滤、MLP5分钟成本过滤、MLP15分钟成本过滤。统一k=30、概率门槛0.55、成本门槛1.5倍+1bps。验证目标仍为净收益率−0.5×最大回撤，至少5个完整交易，无正评分则持币。

所有股票的候选与旧规则对照选择先写入selection.json，再测试。旧规则对照的测试用于比较，不用于调整增强方案。因同一批已冻结方案依次测试，后测试方案可能被保守地标成已有测试暴露；必须结合冻结文件理解，不能以此为由反复调参。

本轮预定新数据：Alpaca SIP原始一分钟行情，AAPL/AMD/NVDA/SOFI/TSLA；2025-08-01至09-16训练、09-16至10-01验证、10-01至11-01最终测试（右端不含）。已有2025年6—7月实验仅作为设计背景，不能当成新测试。参数在新验证前确定；测试后不再改策略或模型超参数。
