# 入场稀疏诊断与仓位联合决策

## 为什么大部分结果没有交易

固定规则、模型预热、概率门槛、预测收益成本门槛串联。即使每项单看合理，联合通过率也可能趋近零。不能用模型所有分钟的拒绝数解释被拒订单数，应只分析实际规则候选时刻。

本地用户实验 `d559a52b4fed493a86f013ee31f0052d`：训练截至2025-04-21，验证截至2025-05-09。验证期规则候选1250个分钟，预热57个，概率低于0.55的1190个，只有3个放行。候选概率中位数0.489，90%分位0.516。纯规则有134笔完整交易，但扣费损失1.40%；仅取消模型不是可接受的盈利改进结论。

收益预测还存在尺度不平衡：旧GRU将收益bps除以100，再使用delta=0.1的Huber损失，与量级约0.69的分类损失直接相加，收益头对小幅价格变化的梯度较弱。网络更复杂并不自动获得可覆盖交易成本的预测优势。

## 新能力

### 规则

`adaptive_intraday` 将滚动成交量加权均价用于局部回归目标，避免持续下跌后仍假设开盘以来VWAP一定能回到；另有上升状态的均线触碰/恢复入场。拒绝强下降状态的均值回归，保留ATR止损止盈、时间退出、冷却、每日次数、日损失限制和成本空间检查。新的规则不是原规则的隐式修改，既有冻结实验继续使用原算法。

### 模型训练

`return_normalization=true` 对GRU启用开发期收益标准化。尺度为教师训练段收益bps的标准差，限制在5—200bps。统计不使用教师反馈段、验证集或测试集。回归损失使用标准化单位与delta=1；分类头仍预测原定义的上涨概率。预测时还原bps，在线更新使用同一冻结尺度。旧模型没有尺度字段时使用100bps，保持原输出含义；模型保存为CPU张量，继续支持CUDA/MPS/CPU。

### 联合决策

`decision_mode=strict` 保留概率和可选收益成本硬门槛。

`decision_mode=risk_scaled` 仅与增强规则搭配。规则选机会并给出风险预算；模型按下式缩放计划数量：

- `confidence = clip((p - 0.45) / 0.15, 0, 1)`；
- `edge = clip(expected_return_bps / max(round_trip_cost_bps, 1), 0, 1)`；
- `fraction = 0.25 + 0.5 × confidence + 0.25 × edge`。

概率低于0.45且预测收益为负，或预测收益不高于负的往返成本时否决。非有限输入或无法计算成本时拒绝。前2k观察仍不入场，在线学习只用成熟标签。这里没有最低成交配额；没有规则机会依然不交易。

此模式刻意不要求弱模型对每笔交易给出足以覆盖费用的收益均值。它的假设是规则具有机会价值，模型用于调节暴露；必须以扣费验证结果检验，不能把非零成交等同于优势成立。

成交仍在次分钟开盘，按模型比例缩小规则仓位，不改变风险上限和参与率。缩仓后最低佣金占比升高，因此对每次新模式入场（包括100%比例）按实际开盘价、股数重新计算成本空间；不满足则放弃。

## 检查与复现

回测结果新增每股候选分钟、模型拦截候选、实际买入、未成交尝试和规则未触发原因。动态曲线提供当前规则原因和模型风险比例，最终统计只在回放末尾显示。

`scripts/compare_entry_fusion.py` 用同一时间序列模型的已完成分钟预测重放不同规则/联合方式。预测仅依赖行情、成熟标签和误差反馈，不依赖策略持仓；重放时重新计算各个资金路径的成本与仓位，不能直接沿用另一条路径的allow_entry。包含验证前后半段、各股成交覆盖和1.5倍交易成本压力。

旧实验和发布快照保持不变。新配置需新建冻结实验；既有测试区间暴露仍按原规则追踪。
