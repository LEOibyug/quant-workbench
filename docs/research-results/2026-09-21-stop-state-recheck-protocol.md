# 止损状态修复后重验：运行前协议

发现旧引擎forced_exit仅在空仓且targets==0时解除，但每日调仓先写入正targets，可能使止损股票永久禁入。已用合成恒定目标例复现：每日调仓清仓后没有后续买入，5日调仓可以重入。这是调仓频率引发的非预期状态差异，不是根据收益调节策略。

固定语义：单股强制退出只持续到清仓完成；日终处理新目标前，若已无持股就解除单股标志。新的收盘目标最早次日开盘成交。部分清仓继续强制退出。独立组合永久熔断不解除。未改任何信号、风险阈值、成本或调仓参数。

重验上轮OLMAR/等权全部24组及每日/5日等权跨期16组，共40次。结果另存stop-fixed前缀，绝不覆盖旧数据。结果好坏均保存；即使修复后出现正收益，也不是独立确认样本。此前涉及单股止损并重入的历史报告均使用旧语义，数值不能自动当作新版引擎结果。后续策略结论须以修复引擎重新确认。

40次完成后追加已发布固定三专家的原三池×正常/双倍费用6次重验，仅核查原参考结果对实现修复的敏感性，不选择或调参。
