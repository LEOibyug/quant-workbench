# 内部人公开申报：数据可行性先行

读取Cohen/Malloy/Pomorski《Decoding Inside Information》期刊DOI10.1111/j.1540-6261.2012.01740.x的Crossref摘要；NBER题录w16454，未读全文。摘要区分例行交易与具有信息的非例行交易。本轮只核查Form4时点/内容可得性，不声称复现分类或直接交易。

固定已有三个池34企业，利用已有SEC submissions缓存统计Form4/4-A覆盖、提交日、acceptanceDateTime。当前缓存列出的最早申报不等于企业历史首单或完整覆盖；不得以无记录作为从未内部人买入。缓存缺acceptance时点不能靠transactionDate替代公开时点。

取ACN、ADP、COP三家公司各自在2025年8月最早一份Form4作为XML访问探针；缺该月则保留缺失，不换成有买入的文件。目标是从原始XML读取非衍生交易代码、交易日、数量、价格、取得/处置方向、期末持有、关系类型及脚注引用；代码P只说明公开市场或私下购买，不能自动等同公开市场交易。A奖励、M行权不能当现金主动买入。

文件只通过公开SEC来源读取，保留URL/HTTP状态/SHA；不输出申报人住址或其他无关个人资料，不发送消息。禁止把申报日期前的交易日期当信号入场日期，也不因当前文件内容反选样本。无法取得XML时明确只完成元数据覆盖，不以缺内容推断无买入。

未来策略若使用本信息，至少需同一内部人的多年历史来分辨例行行为，处理更正/重复申报、价格缺失/区间脚注、间接所有权及10b5-1计划；这些没有实现前不输出适用性结论。本轮不下交易、不训练分类器、不改网页。
