# 库存与销售成本变化：文献及可计算性审计

本轮尚未构造交易账户。目的是判断库存信息是否提供不同于应收账款的经济机制，以及已有历史是否足以支持下一步研究。所有接口输出仍为“证据不足”。

## 已核实文献

Thomas与Zhang，Inventory Changes and Future Returns，DOI 10.1023/A:1020221918065。已从[Springer文章页面](https://link.springer.com/article/10.1023/A:1020221918065)读取原始摘要，并用Crossref核验题名作者。摘要报告应计项目与未来异常收益的负相关主要与库存变化有关；作者检验的三种解释未获支持，进一步讨论需求变化及盈利管理的可能作用。

只读取摘要，未取得全文，不声称复现其变量、分组、样本或回报。摘要不能证明当前大盘股中库存上升必然不利，也不证明它们存在盈利操纵。

## 本轮数据代理

I=(InventoryNet_t/Cost_t)/(InventoryNet_(t−1)/Cost_(t−1))，使用同份已公开10-K/10-K/A、前后相同成本标签，成本标签预定为CostOfRevenue、CostOfGoodsAndServicesSold、CostOfGoodsSold。它是期末库存相对年度成本的变化代理，不是采用平均库存的完整周转率，也不是上述论文的库存变化/资产定义。

较高I可能来自需求不及生产，也可能来自备货、供应链缓冲、投入品通胀、成本确认方法、并购、汇率或产品结构。制造和零售有实物库存经济机制，但混合业务的总成本可能含服务成本；即使同年报标签一致，也不能直接跨行业比较。

保留上一轮的公开时点规则：filed严格早于判断日，年度跨度330—380天，前后财年末相隔330—400天，最新年度不超过550天。缺标签不补零，不把原材料、在产品及产成品直接相加替代净库存，以免重复口径和减值准备漏记。

## 覆盖和验证

已有50家公司缓存的2022/2023/2024/2025年9月1日，可计算数分别28/29/28/28，总计113条。完整公司列表、数值与来源在inventory-audit.json。仍继承旧会计排除范围，没有将剩余公司自动认定为业务可比；例如包含混合业务公司的少量存货，不能把它们视为库存主导企业。

113条同申报、同成本标签、filed早于判断日检查通过；NVDA未来申报数值扰动不改变历史输出，移除InventoryNet返回不可计算。代码静态检查通过。这些检验证明字段处理的部分性质，不证明预测有效。

下一步需要事前限定经济范围并制定交易/无筛选/相反方向对照，区分库存代理与公司身份、财务缺失和并购影响。不能先看收益再决定哪一种库存口径或行业符合理论。总体目标未完成。

复现：`uv run --locked python scripts/audit_inventory_quality.py`；单股查询加 `--symbol NVDA --date 2025-09-01`。无网络或密钥读取。
