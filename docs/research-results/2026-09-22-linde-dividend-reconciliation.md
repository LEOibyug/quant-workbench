# LIN股息：发行人对账与重复权益处理

本轮完成发行人股息表与供应商22条LIN记录的对账。23行官网历史记录中，20条供应商记录可按登记日、支付日和金额匹配（包含两个重复身份记录）；另外两条支付日冲突保留。未将这些记录批量标为可交易或完整时点数据。

## 2023年重复项的经济权益已确认不能相加

[官网证券与分红页](https://www.linde.com/investors/stock-and-dividend-information)明确当前CUSIP为G54950103，2023-02-28宣告每股$1.275，2023-03-14登记、2023-03-28支付。

[SEC 8-K12B](https://www.sec.gov/Archives/edgar/data/1707925/000119312523055949/d459315d8k12b.htm)说明2023-03-01旧公司被吸收合并，旧股1:1换新股，新公司承接旧公司全部义务。[发行人Form 8937](https://assets.linde.com/-/media/global/corporate/corporate/documents/investors/delisting/irsform_8937.pdf)第1/3页将G54950103与该次重组后发行人关联，第4页说明1:1成本基础延续。

SEC companyfacts的2023年一季度CommonStockDividendsPerShareCashPaid为 **1.275 USD/shares**（2023-04-27申报，accession 0001628280-23-013457），进一步核对该季度每股总额，并补充美元单位证据。这是事后会计勾稽，不能拿4月27日的资料声称3月交易时已知。

因此，对于连续持有并在重组中1:1换股的一份LIN经济持仓，不能按供应商两条不同CUSIP记录重复计成每股2.55美元。研究归并记录使用重组后已确认CUSIP那条作为规范候选，并保留两条原始ID。它是发行人层面的权益归并，不是宣称供应商已明确取消旧ID。旧CUSIP的直接历史申报请求返回403，该文档未作为证据；旧CUSIP完整映射仍未独立核验。

官方表只有宣告、登记、支付日，不包含除息日。2023-03-13仍仅来自供应商；税务、真实净到账与历史首次可见性也没有因本轮自动解决，所以规范候选 `book_ready=false`。也不把其他时间的两条相似记录机械合并。

## 实现与复现

运行 `uv run --locked python scripts/audit_linde_dividends.py`，使用本地已取得的官网表、SEC缓存和历史供应商记录。解析器核验表头，兼容06/4/2026这类单数字日；不把解析失败当成该次未分红。JSON保存全部23行发行人记录、22条供应商对账、冲突、重复归并、季度USD单位来源及文件哈希；来源URL/成功与失败状态见linde-dividend-sources.json。

本轮没有增加策略盈利数字或修改网页。分红账本的数据资格缺口缩小，但仍需除息规则/口径核验和端到端账户接入，之后保持原策略参数再测。总体研究目标未完成。
