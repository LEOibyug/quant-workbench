# 盈利稳定性的可计算性与下一年盈利误差

结论：严格口径每期可覆盖51—53家企业，低波动组四期均具有较小的下一年度盈利绝对预测误差。这只支持本代理与盈利变化尺度的关系，不能据此宣称股票交易获利、企业适用边界已成立，或金融等排除组不适用任何策略。

## 来源及定义

事前协议81b3186。读取Dichev/Tang的SSRN摘要10.2139/ssrn.927305，核验期刊题录10.1016/j.jacceco.2008.09.005；未读正文，不声称论文复现。原quality-value含三年波动，本次隔离五年标准差而非把既有概念重新包装成新策略。

指标为连续五年度NetIncomeLoss/该年度末Assets的样本标准差。每年最早已公开10-K、资产利润同申报、全年330—400天、年度末连续、最新年度≤550天，缺失或冲突拒绝；不用事后修改财报回填。负利润保留，并记录盈利年度数和均值。它不是以平均资产计算的标准ROA，不是经营盈利，不代表现金利润。来源为当前SEC快照，尚不能证明历史接口当时的可用范围和每次企业重组连续性。

固定74企业，沿用已有会计范围和身份条件；各年17家被该口径排除，余下缺失不替换名单。以判断时点整个可计算池的三分位分类；不依赖行情收益。未来标签为下一连续年度同口径盈利，预测器仅沿用最近年度值。未来财报仅作标签，分组不以标签是否完整为条件。标签公开截止2026-09-22。

所有初始可计算样本恰好都取得下一年结果，未因未来缺失删样本；完整JSON保留中间组、均值、盈利水平、阈值及逐股来源。上述百分点是净利润/资产的预测误差单位，不是股票收益率。

低波动组的平均历史盈利水平也明显较低（约7.86%—8.28%，高组约12.78%—13.93%），未控制盈利水平、行业、资产结构及估值。低历史波动对应低未来绝对变化，也可能只是尺度持续性；不能将此表称为发现独立超额收益、因果效应或校准概率。每年重复大量相同企业，四个日期不是数百个独立确认样本。

## 单股审计方法

运行 `uv run --locked python scripts/audit_earnings_stability.py --symbol MSFT --date 2025-09-01`，返回每年的来源与标准差，以及正式状态“证据不足”。该命令只做原始财务条件审计；低/高分组依赖完整股票池，应使用本轮审计结果，不是股票的永久标签。2025截面MSFT属于低组、AAPL属于高组；这不是买入或卖出建议。

未来申报数值扰动的296项检查全部不改变事前指标。合成检查验证负盈利不删除、单位缩放不变、缺失/冲突拒绝，以及后续比较报表不覆盖首次申报。全部来源与输入SHA256留档。

下一步需要先固定交易规则及盈利水平对照，再检验低波动条件是否改善同资格共享资金账户的费用后收益和风险；机制表不能替代这一步。仍须处理公司行动、总回报、当前身份与历史会计连续性限制。总体策略与适用性目标未完成。
