# 边际标签稳定性诊断（运行前固定）

目的：判断“某股票长期适用”是否得到已有边际标签支持，以及释放资金的处理是否改变资格结论。不是训练新交易策略，不修改标签效用系数。

1. 月度标签沿用49组，验证仅原8组。比较冻结训练总体均值、冻结训练逐股票均值、判断时已成熟的该股最近标签。最近标签的结束日必须<=当前决策日，允许使用之前已成熟的验证标签，模拟在线观察；其余两基线不更新。
2. 报告MSE、每日期组排名相关、预测正组和非正组真实效用、逐日期结果。零值单独统计，不将零默认为适用/不适用。不以160行作为独立样本，不计算夸大精度的显著性。
3. 年度标签比较相同股票/年份的留现金与比例重分配两种干预，统计符号相反、零值与差异；再比较前后两年度的符号稳定性。只有两年，不能外推长期企业属性。
4. 保留所有结果，不按诊断结果反转标签、调门槛或选择赢家。若简单身份均值也无效，不能仅凭“同一股票过去适用”发布永久资格；若干预改变符号，应要求接口显式传入资金分配方式。
