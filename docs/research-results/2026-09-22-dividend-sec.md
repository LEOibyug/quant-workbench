# 62股现金分红与年度SEC金额勾稽

完成批量勾稽，发现拆股单位、支付时点和字段语义都可能使简单年度求和失效。本轮没有调整策略或把金额吻合自动升级为事件验证。

## 固定规则与覆盖

协议6f13b1b先于结果。只取CommonStockDividendsPerShareCashPaid的USD/shares、10-K/10-K/A年度330—380日记录，2022—2025财年末；同年选缓存中最早提交文件，按供应商payable_date在该财年内汇总。未用Declared代替CashPaid，未自动删除身份重复或调整税率。

62股中37股缺该年度标签，不能解释为没有分红。其余出现68个精确数值吻合、1个一美分内接近、13个明显差异、5个左侧窗口缺口、4个无供应商事件的公司财年。实际可比较的24家公司合计82个财年。它们不是独立策略样本，也不是全部已经验证的分红。

NEE一个年度SEC为2.27、供应商合计2.2660，仅列作报告精度差，不自动判为严格吻合。供应商所有事件缺显式币种，SEC USD单位只为会计对照，不证明每笔真实到账币种/税务。

## 已核实：AVGO拆股单位问题

取得并读取[Broadcom 2024-06-12官方财报公告](https://investors.broadcom.com/news-releases/news-release-details/broadcom-inc-announces-second-quarter-fiscal-year-2024-financial)，确认10拆1、7月15日起按拆股后价格交易，及3月29日已支付每股5.25美元。

供应商该财年四笔金额为5.25、5.25、5.25、0.53，直接相加16.28。将拆股前每股金额除以10，3×5.25/10+0.53=2.105，与该年度SEC披露精确一致。因此此处不是找到额外14.175美元分红，而是同一个“每股”在年度中改变了单位。

但官方公告明确3月29日已支付，供应商payable_date为4月2日。这个时点冲突未解释，不能由金额勾稽直接推定供应商支付日可靠。上述拆股处理只用于本项会计对照，没有自动修正所有行情、交易股份或历史成本。

## 未解决的差异

V及SPGI个别记录供应商求和是SEC数值4倍，可能涉及单次派息与年度标签的语义差异；当前标准标签说明为“Aggregate dividends paid during the period”，故不能仅凭4倍关系就改写它为季度值或乘4。仍需原始报表上下文。ACN出现0.75比值也不能仅凭比例认定25%扣税；AMT可能涉及期间或金额口径，均保留未解释。

尝试的V、AVGO、ACN原SEC文件请求均403，年报镜像均404；ACN官方页403、V页429。仅AVGO上述公告200并实际读取，不将失败请求冒充证据。抓取状态、链接和哈希见dividend-sec-evidence.json。

## 使用边界及复现

运行 `uv run --locked python scripts/audit_dividend_sec.py`。dividend-sec.json保留逐公司财年SEC来源、供应商事件、重复日期、差异与源文件哈希。金额精确吻合不证明除息日/支付日/身份/首次可见时间均正确，也不允许直接设置verified=true。没有静默调整13项差异。

本轮进一步缩小数据错误范围，并明确为什么跨拆股分红不能简单相加。后续应处理真实单位和来源冲突，再按原参数重跑账户，而不是凭这些差异解释或包装盈利策略。总体研究目标仍未完成。
