# 策略适用性判断：交付约束与验证方案

用户补充要求：若最终交付企业适用性说明，必须同时提供一种能判断指定股票是否适用的方法。仅列出企业类型、历史赢家或解释性故事不构成完成。

## 必须可调用的接口

输入：股票代码、判断日期、目标策略版本；数据为该日期之前实际公开的财报，以及截至判断时可用的历史行情。输出必须同时包含：

- `status`：适用、不适用、证据不足；
- 数据覆盖区间、财报公开日期、指标来源与缺失项；
- 每条规则的指标值、固定门槛、通过与否和经济解释；
- 适用的具体策略或专家，不把“好公司”泛化成任何策略都适用；
- 判断有效期及复评触发条件；
- 方法版本、验证样本范围、适用边界与尚未证实的部分。

“适用”只代表符合已验证的策略使用条件，不代表下一笔或任何时期都盈利。数据不充分时必须给出证据不足，不可当作差企业或用零值替代缺失。

## 分层结构

1. **数据与会计可比性**：历史足够、财报公开时点明确、无无法处理的公司行动、财务口径可比。金融/保险/REIT不直接与一般经营企业按相同毛利润/资产模型比较；行业分类也需要判断时点信息，当前SEC SIC只能作审计说明，不能冒充历史时点标签。
2. **企业经济条件**：候选包括盈利与经营现金流持续性、资本回报、现金流和利润差异、业务或杠杆风险。条件必须对应专家假设，不能看见历史收益后倒推出“适用行业”。
3. **当前可交易状态**：趋势策略看趋势持续与风险；反转策略需区分相对短暂价格偏离与持续恶化。流动性与费用可行性作为共同条件。价格状态变化可以使同一公司从适用变为不适用。
4. **验证后的决定规则**：先固定候选门槛及缺失处理，再比较通过/未通过组的策略净收益、相对等权改善、回撤、成本敏感性、覆盖率及拒绝率。阈值若在开发期选择，必须另设未使用的确认集。不能把全部股票拒绝、全部持币当作发现有效策略。

## 待证而非已证

当前30公司SEC面板属于数据可行性与假设诊断；2025—2026的三个股票池表现已知，不能声称在看到这些结果之前提出新财务条件。三年净利润和经营现金流为正只是候选条件，尚未验证其能够区分任何专家的收益，不允许直接对外输出“适用”。最终判断器必须依托固定规则的后续验证，否则输出应保留“证据不足”。

交付验收：能对任意输入股票给出可审计的三态结果（不保证任意股票有足够数据）；至少演示通过、未通过、缺数据三类路径；时间截断和财报后修订不污染当时判断；在独立日期或股票池上验证判别能力，完整报告失败与覆盖率；报告中的定性解释与程序规则一致。

## 可操作的判断对象与数学定义（2026-09-21 补充）

不能给股票一个永久标签。判断对象应为 `(股票、策略版本、判断时点、持有周期、股票池、费用、当前持仓)`。同一股票可以适合趋势专家而不适合反转专家；同一专家也可能随行情变化而失去适用条件。横截面排名与共享资金分配依赖整个股票池，不能仅输入单股价格便声称得到完整组合结论。

建议将判断分为两个独立输出：

1. **策略匹配**：数据充分且符合目标专家的可检验假设。例如趋势专家考察多尺度趋势方向与稳定性；反转专家考察偏离后的回归速度、参数稳定性及费用后的可交易幅度。模式相似度只描述价格形态，不能直接解释为盈利概率。随机游走检验被拒绝也不等于存在均值回归或可盈利机会。
2. **资金分配价值**：在当前组合约束下，这只股票能否提高组合效用。相关性过高、流动性不足、换仓费用高或其他机会更好，都可能使匹配股票获得零权重；零权重不等于股票被永久判为不适用。

研究标签应尽量与实际账户目标一致。候选定义为：在相同起始资金、其余股票、费用、执行规则、风险约束下，比较允许股票 `i` 使用专家 `k` 的组合与禁止该股票使用该专家并按相同规则重新分配资金的组合：

`ΔU(i,k,t) = U(允许组合, t→t+H) − U(禁止组合, t→t+H)`。

`U = 净收益 − λ × 风险惩罚`，周期 H、风险度量、λ 和资金再分配规则必须在评估前冻结；交易成本已经包含在净收益中，不再重复扣减。两个组合都要计入部分成交、共享现金、仓位上限、止损与现金收益的相同假设。该差值是依赖模拟器的策略消融值，不是观测数据识别出的因果效应；多支股票的交互作用也使它不能简单相加。

模型只接收 t 时点可用特征；未来 ΔU 只能作为历史训练标签。当前 utility-router 使用单股专家影子收益，尚不等于上述组合边际效用，这一差距必须保留在结果说明中。

## 决策门槛如何建立

以下是待验证的方法约束，不是已经实现或证实的新策略：

- 开发期拟合条件效用，校准期固定门槛及拒绝规则，随后锁定版本。重叠的观察窗口和收益标签需要时间隔离；同一日期的股票样本不能当作相互独立的证据。
- 在未用于选择规则的跨时间、跨股票池确认集检验：通过组是否比未通过组具有更高的费用后效用，以及完整共享资金账户是否优于不筛选的同策略基线。另列等权持有、现金、双倍费用、回撤、换手、覆盖率和各池结果。较低回撤但几乎全部持币不算筛选有效。
- 使用保留日期内股票相关性的时间区块重采样评估组间改善的不确定性，并处理多策略、多门槛搜索带来的选择偏差。模型预测的 bootstrap 分位数只表示拟合不稳定性，不能冒充未来收益的置信下界。
- 只有确认后的规则、完整数据及当前条件都通过，才允许输出“适用”；确认规则明确排除的条件输出“不适用”；缺数据、超出确认范围、置信不足或尚未完成确认均输出“证据不足”。规则未通过与已证明策略无效是不同结论。
- 每个新交易日收盘后复评；新财报、公司行动、股票池/费用/持仓变化时重算。盘中不得使用尚未完成的当日日线。

## 当前可调用示例与真实限制

在仓库根目录运行，无需读取 API key：

```bash
uv run --locked python scripts/check_strategy_applicability.py \
  --symbol AAPL --date 2025-09-01 \
  --prices artifacts/research/annual-momentum/original20.parquet --price-only
```

本次实际输出：候选条件“通过”，正式状态“证据不足”。收盘价 232.14 高于 126 日均价 210.8208，63 日对数动量 0.14478 为正，20 日成交额中位数约 108.80 亿美元，高于固定门槛 1000 万美元。这只是既有趋势/流动性候选条件审计，不是推荐 AAPL，也不是所有专家通用的适用性判断。去掉 `--price-only` 会增加本地 SEC 财报条件检查，缺少财报时保留缺失原因。

该脚本尚未实现上述组合边际价值判定；其价格数据审计也没有完整覆盖陈旧报价、重复交易日和公司行动。模型判断脚本 `scripts/judge_learned_applicability.py` 另有共同交易日覆盖与陈旧行情检查，但同样未获适用性确认。当前工具只用于研究审计。

最新效用路由实验的均值模型在三个池分别约 +11.85%、+29.61%、−7.76%；保守模型约 +0.03%、+2.39%、−5.31%。这些结果不支持宣称已建立可靠的筛选器。已反复查看的三个股票池及历史年份只能继续用于开发与诊断，不能重新称为独立确认集。当前总体研究目标仍未完成。
