# 一年高点与年度动量：三股票池开发实验

文献原摘要认为价格接近52周高点包含不同于历史涨幅的信息：Thomas J. George、Chuan-Yang Hwang，The 52-Week High and Momentum Investing，Journal of Finance (2004)，DOI 10.1111/j.1540-6261.2004.00695.x。读取的是Crossref提供的原摘要，没有宣称已读全文或复现论文样本和交易设计。

## 固定实现

high52按当前收盘/过去252个收盘最大值排序；momentum12_1按log(P[t-21]/P[t-252])排序。前25%（向上取整）按63日逆波动分配95%预算，逐股截断20%，剩余现金不重新分配；equal为95%等权。全部按63日收缩协方差向下缩放至预测年化10%波动，不加杠杆。代码序打破并列，每20个交易日执行，保留原共享资金、分批、费用、止损和组合熔断，采用修复后的单股止损状态。

不加绝对趋势门槛：即便全池下跌，仍可能买入相对领先股。排名法只是跨股票相对选择，不是企业适用性判定。收盘高点不是日内最高价；20交易日并非严格自然月。这是明确的只做多候选，不是原论文精确复制。

原三个池补齐2024-08-01至2025-02-28预热并拼接已有行情；每股共522交易日，评价前271交易日，无缺交易日、重复股日或触发疑似拆股跳变守卫。随机池使用既有更早缓存。数据清单及SHA256见annual-momentum-data.json；上市/代码存活偏差与原样本一致。

这些股票池和评价年经过反复查看，以上只是候选发现。已经冻结规则转入high52-temporal-protocol的跨时期确认，不根据当前赢家调参数。1项针对性测试覆盖未来行情不影响过去目标、行序与单股名义价格单位不影响目标。

复现：先 `uv run --env-file .env --locked python scripts/prepare_annual_momentum_data.py`，再运行 `uv run --locked python scripts/study_annual_momentum.py`。原行情和密钥不入Git，准备脚本只从环境读取凭证且不打印。评估无需联网。完整指标/净值为annual-momentum.json，逐日持股明细无损压缩于同名full.json.gz。config固定组合名仅为注入入口，实际策略见candidate。
