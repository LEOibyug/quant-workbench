财务资料只覆盖两个20股池各10股，所以两池均有50%的股票日缺少财务依据而被排除，不能把这两组收益降幅解读成质量投资失效。随机10股有10%股票日因财报陈旧而证据不足。当前覆盖与会计可比性仍不满足正式企业适用分类要求。此轮用于诊断，并非独立确认。

## 可运行的判别原型

```bash
uv run python scripts/check_strategy_applicability.py \
  --symbol NKE --date 2025-09-02 \
  --prices artifacts/research/random-universe-2026-09-21/daily.parquet
```

输入股票、判断日及日线文件。财务数据从本机SEC缓存读取，未取得时明确列出缺失。输出固定版本、每条条件的数值/阈值/通过情况、缺失原因、实际财报提交日期、再评估触发条件。`candidate_status`区分通过/未通过/证据不足；`status`目前一律为证据不足，因为尚未通过独立验证。不能把原型规则通过当作可以交易的推荐。

价格条件为半年均线以上、季度收益正及20日中位日成交额至少1000万美元；企业条件为三个可比完整年度净利润/经营现金流为正、现金流累计覆盖利润、最新收入不降，且财报不过时。理由和边界已在事前协议固定。这些条件看起来合理，但本轮结果不足以确立其交易价值。

## 对上一轮财务审计的更正

NEE的通用收入标签只能对齐到2012、2011、2010年度。上一轮“三个完整年度”检查未同时检查陈旧性，因此“随机10股全都通过三年盈利现金流条件”不是有效的截至2025年近期质量结论。此次门控明确将NEE判为证据不足。应更正为：其余9股有近期记录且通过最宽松盈利/现金流正值条件；NEE无法从当前通用字段可靠判定。这反映财务字段映射和数据时效检查的必要性，不能用旧数据代替近期数据。

本轮已加入550天陈旧阈值及330—400天年度间隔检查。下一阶段需要补齐缺失企业、处理特殊行业及收入标签可比性，并使用独立时间数据；不能靠不断叠加条件追逐同一年收益。

## 核验

4项有针对性的测试通过：财报公开边界、未来重述不回填、价格判断不受未来行情变化影响，以及缺失数据和未通过规则的区别。脚本通过静态检查，未改网页和生产策略，结果只是研究候选。
