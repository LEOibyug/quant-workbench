# 逐资产指数梯度共享资金：运行前协议

依据：Helmbold等《On-Line Portfolio Selection Using Multiplicative Updates》，DOI 10.1111/1467-9965.00058。本轮读取Crossref原摘要，作者网页及正文访问失败；来源保存于eg-source.json。以下是自行明确的约束指数梯度算法，不声称完整复现论文或继承其财富保证。区别于既有online-mixture的三个策略账户财富加权，本次直接更新股票与现金的权重。

原理：最大化单期对数财富的梯度为 x/(b·x)，用负熵作为更新距离可得 z_i=b_i exp(η x_i/(b·x))，归一化后得到下一期配置。固定η=1，只检验该版本，不搜索学习率。股票x为收盘价比值，现金x为既定滞后SOFR账本同期增长；不使用未来收益。梯度减去共同常数以避免指数溢出，不改变归一化结果。

约束投影为最小KL距离：b_i=clip(c z_i,l_i,u_i)，选择c使权重和为1。股票上限20%、下限0，现金下限5%、上限100%。初始股票合计95%等权、现金5%。第一个评估日之前的最后交易日发出初始目标，随后每次收盘使用刚观察到的价格比更新，下一开盘按原引擎执行；没有用评估前数年的赢家初始化。缺共同报价、重复日期、非正价或无利率覆盖直接失败。

对照为每天恢复上述初始固定权重。两者以截至当日的63日对数收益LedoitWolf协方差，将股票部分按min(1,10%/预测年波动)同比缩小，余款持币。影子EG权重不因实际成交/风险缩放反馈重置，必须明确这是目标分配过程而非已实现财富；真实账户执行才用于评价。

固定random10、旧transfer12、新12三历史池，连续2022-09-01至2025-09-01（不含终日）；273日预热，正常/双倍既有费用，EG/固定两法，共12账户。统一10万美元共享现金、每日决策、原分批/整股/单股止损/永久组合回撤停机，现金统一SOFR情景。纯现金按最后实际收盘对齐。已看过的行情仅作开发诊断。没有完整股息，价格收益不等于总回报；SOFR不保证券商实际可得。保留所有账户和逐日档案。

核验：投影约束、相同比值不改变权重、上涨资产相对增加、价格单位缩放不变、实际数据截断不改变历史目标、逐日资金守恒、固定分配对照独立计算。报告两费用下收益/回撤/暴露/换手、相对固定与现金的效果；降低参与或单池胜出不视为完成。股票获得零/低权重不构成“不适用”证明，不升级现有三态判断器。
