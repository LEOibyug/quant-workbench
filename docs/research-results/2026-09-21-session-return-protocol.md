# 隔夜/日内机制可行性筛查：计算前协议

对三个固定股票池，先逐股核验：日内log(close/open)之和，加评价区间内相邻交易日隔夜log(open[t]/close[t-1])之和，等于log(末收盘/首开盘)。不包含评价首日前隔夜，不纳入末日后的未来开盘。分项百分比不能直接相加。

固定三个机械模式：每日日内持有（当日开盘买入、收盘卖出）、每日隔夜持有（当日收盘买入、下一交易日开盘卖出）、全期买入持有（首开盘买、末收盘卖）。每个完整轮次开始时以95%现有现金等额分配，5%缓冲现金；无股票筛选、无当日价格信号、无训练。三池×三模式×0/正常/双倍费用=27组。

这是分数股、按金额成交的理想化拍卖撮合账户，不是现有整股/流动性约束引擎。预定固定金额订单在开/收盘价格形成前提交，假设支持实际成交价确定分数股；没有用成交时价格形成选股信号。真实券商是否支持这种订单、收盘前保证金与成交量限制尚未验证。不使用这些结果宣称可部署。无单股止损/组合熔断，因此净值风险也不等同现有引擎。

费用沿用原初始资金、半价差+滑点、逐股佣金下限/每股佣金、卖出费；每轮为实际买入成交价/卖出成交价算现金，双倍场景全部翻倍。全期持有也计末次清仓成本。没有现金利息或实际分红。本筛查只判断收益时段与周转成本是否值得进一步构建完整交易引擎；不能把无成本正收益当作有效策略。所有池与年份已被多次研究，非新独立验证。
