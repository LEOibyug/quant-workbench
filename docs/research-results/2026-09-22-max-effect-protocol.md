# MAX尾部偏好：运行前协议

读取Bali/Cakici/Whitelaw的NBER WP14804摘要，DOI10.3386/w14804，2009（JFE发表于2011）。摘要定义过去一月最大日收益MAX，报告高MAX与后续收益负相关，动机为彩票型收益偏好。未读全文，不声称复现原文。既有毛利润/低投资组合已检验失败，不重做为新发现。

候选MAX_i,t=max(r_i,t−20,...,r_i,t)，r为简单收盘收益，21交易日窗口。63日完整共同日历与正价格为基本资格；按MAX从低到高取floor(N/3)最低/最高组及全部资格对照，至少3支；低高分界同值则全组持币，防止代码排序产生虚假信息。无财务会计筛选，避免沿用资产增长特有筛选。原始拆股调整价格口径沿用缓存，公司行动/分红缺口保留，不冒充总回报MAX。仅当前已知收盘用于信号、次日执行。

每20交易日决策；逆63日波动、LedoitWolf协方差、10%年化波动向下缩放、每股≤20%、共同预算min(.95,.2*floor(N/3))。原共享资金100000、整股分批成交、成本与永久停机均保留。低/高/全部组预算相同但实际风险和仓位未必相同，不将差值作为纯MAX因果效应。

旧三池与新12最新一年；随机10与新12历史三个年度及连续三年，共12窗口×3模式×正常/双倍成本=72账户。不调21/63/20周期，不反选高组，不剔除失败股票。所有样本均已在历史研究查看，是开发诊断，非独立确认。原价信号受未完全核验公司行动影响。

检查：简单收益MAX合成例、价格单位不变、未来截断不变、权重/分组约束；源数据哈希、72档案完整。单股判断器输出原始MAX/池内排名/候选组及正式证据不足。若跨池跨期不稳定，则不认定已建立适用边界。
