# 连续信息动量：条件配对与共享资金检验

结论：本实现未形成可靠的股票适用性判别。不能将“累计上涨且上涨天数较多”直接当作动量策略适用标签。72账户均已完成，但连续组存在多窗口亏损与相对基线劣势。没有改选离散组或重新调整形成期。

## 文献与模型

Da、Gurun、Warachka (2014)，*Frog in the Pan: Continuous Information and Momentum*，DOI [10.1093/rfs/hhu003](https://doi.org/10.1093/rfs/hhu003)。取得[作者提供的期刊PDF](https://www3.nd.edu/~zda/Frog.pdf)，阅读摘要、第一节公式(1)与反例说明，来源哈希见fip-literature.json。旧SSRN摘要与期刊数字不同，本报告不混用其收益数字。

ID=sign(PRET)×(负收益天数−正收益天数)/总天数。PRET为t−252至t−21的231日累计对数收益；与论文自然月、全市场双排序及持有期并不完全相同。绝对值≤1e−12的日对数收益作为数值零，零日仍进入分母。低ID刻画方向频次，而非真正观测的信息流；原文也给出相同ID但跳跃程度不同的反例。

只纳入PRET>0的股票，按PRET邻近两两配对，在每对中选择ID较低者；较高者为反向对照，双方并集为基线。ID相同整对不参与，奇数最后一只不参与。配对不是做空另一只，两组都是独立只多账户。不能将近邻配对解释成完全控制了累计收益、行业或规模。

每20交易日收盘决策、随后按原引擎成交。三个账户共享相同预算上限，逆波动分配、每股20%上限、10%年化波动只缩不放，保留共享资金、部分成交、止损和永久组合停机。年度重置与连续账户分开。冻结协议提交49bfa04早于账户运行。

## 可调用判断及边界

运行 `uv run --locked python scripts/information_continuity.py --prices artifacts/research/annual-momentum/original20.parquet --symbol AAPL --date 2025-09-01`。仅使用判断日期前完成的交易日，返回形成期、PRET、ID、配对股票与候选通过状态，正式状态为证据不足。AAPL此例形成期动量为负，未进入配对，不代表股票或其他策略永久不适用。

需要完整股票池；同一股票换股票池会改变比较对象。缺股票/历史不足/行情超过7自然日给出证据不足。此工具是研究条件审计，不是实盘交易资格或交易所日历的完整核验；周末/长休市处理仍为保守代理。

公司行动及分红未完整处理，当前股票池存在生存者偏差；价格频次也可能受拆股和分配影响。全部股票池和时期曾被用于开发，不是独立确认。原文现象并不因本实验失败而被全面否定。

## 核验与档案

2项针对性测试通过：相同累计收益不同路径、零日分母；合成数据的前缀及单位变换不变性。原始20真实价格也通过前缀与单位变换检查。运行中逐个检查行情完整性、分组互斥、预算及单股权重，72账户与完整压缩档案齐全。来源区间/配对/ID见fip-coverage.json；完整曲线、持仓贡献、费用和风控状态见fip.json及fip.full.json.gz。
