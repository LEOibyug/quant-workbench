# 可调用的股票—策略适配判断与验证 v0

## 结论

已经实现输入股票、判断日期和股票池日线的判断接口，但尚未证明它能可靠区分适用股票。正式状态始终为“证据不足”，候选模式概率单独返回。不能把分类准确率高于基线或少亏解释成交易有效。

此前价格/财务规则判断器 `scripts/check_strategy_applicability.py` 仍可调用，输出规则值和缺失项；其通过条件也尚未获适用性确认。本次是不同的竞争假设，不用机器学习结果覆盖之前失败。

## 如何判断

1. 核查字段、共同历史、正价格、交易日连续性和行情新鲜度。缺数据输出证据不足。至少64个交易日；历史越长越好，因为通道专家有状态，不仅依赖最后64日。
2. 只截取判断日及之前价格。输入64日归一化序列的频谱能量、Haar块差能量、趋势/偏离统计，以及三个现有专家的激活状态。模型不接收股票代码、日期或绝对价格。
3. 输出持币、横截面动量、通道趋势、残差反转四种候选概率。它们是未经校准的分类概率，不是盈利概率，也不是企业的永久属性。分类目标是未来21日哪种影子专家效用最高，属于策略效用预测，并非纯粹描述过去模式。
4. 每日收盘后重评，最早下一开盘执行；股票池变更后必须重算。横截面动量与残差参考整个池，所以结论必须同时注明股票池。
5. 只有候选规则在独立股票/时期上证实判别能力后，才可对外给出“适用/不适用”。目前步骤5未通过，不设置一个看似精确但未经验证的概率门槛。

## 训练与隔离

训练前协议已入Git。原20股历史完整共同尾段为2020-11-30—2025-08-29。数据源以当前代码提供的历史可能包含前身公司，不能将其当作同一企业经济属性已核验；同时存在当前成分存活偏差。

每5日每股取样，3440个训练样本、660个验证样本。训练最后标签到2024-08-27；验证最早输入窗口2024-09-04起，最后标签2025-08-27。两个区间不共享标签或特征窗口。区间内部重叠且股票相关，不能将样本数当独立试验数。未来仅用于成熟标签，每边8bps、末端平仓的二元影子持仓近似，未复现真实账户成交约束。

按预定平衡准确率选择逻辑回归，没有根据下一年的收益选择。未做概率校准，也未做“仅专家激活状态”消融，因此不能把全部分类提升归因于频谱模式。

## 共享资金账户

以各股票的概率混合三个原专家仓位，现金概率保留资金；再限制单股20%、总仓95%、预测波动10%。原专家自身已有风控缩放，最终混合再次检查风险但不放大仓位。保留原共享资金、分批执行、费用、止损及回撤熔断。引擎config中的fixed_ensemble仅作注入入口，实际候选由JSON的candidate字段标识。正常与双倍费用均报告。

## 调用与复现

在仓库根目录：

```bash
uv run --locked python scripts/judge_learned_applicability.py \
  --symbol ACN --date 2026-08-31 \
  --prices artifacts/research/random-universe-2026-09-21/daily.parquet
```

本地已训练产物在 `artifacts/models/learned-applicability-v0/`。接口核验模型SHA256，训练元数据和完整账户结果入Git；原始行情和二进制产物遵循仓库artifacts忽略规则，重新checkout需准备对应行情并运行 `scripts/train_learned_applicability.py`。训练脚本不调用网络，不需要输出或读取密钥。执行评估脚本为 `scripts/study_learned_applicability.py`。

ACN该日返回候选持币39.21%、动量8.13%、通道34.57%、反转18.09%，正式结论“证据不足”。这不意味着39.21%的亏损概率，或该企业永久不适用。缺代码、历史不足、早于模型训练截止日期的请求不会产生有效适用性结论。

针对性验证覆盖未来价格改动不影响当前特征、标签最后使用开盘边界与费用、缺数据/训练期日期拒绝。下一步若研究适配判别，应比较模式特征相对仅激活状态的增量，并验证预测类别条件下的成熟效用；不能按这些评价期结果调整门槛后声称验证成功。
