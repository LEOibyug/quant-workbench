# 成本约束共享资金：运行前固定比较

读取Gârleanu–Pedersen《Dynamic Trading with Predictable Returns and Transaction Costs》NBER WP15205摘要（https://www.nber.org/papers/w15205）。摘要提出考虑信号衰减、向前瞄准及部分调整的动态配置原则，论文实证为商品期货；本项目现有优化器是单期跟踪误差+L1换手惩罚，不是论文闭式动态解。

固定两个信号：fixed_ensemble（5交易日再平衡）与high52（20交易日）。均在annual-momentum清单相同历史上生成目标，避免不同预热数据干扰本轮对照。固定三执行模式：legacy原执行；pooled_only使用cost_aware执行路径但将目标优化器替换为恒等映射，仅启用按比例资金分配、5%现金缓冲、原进场/调仓门槛及日换手预算；cost_aware使用该执行路径和现有成本优化器。

配置沿用原固定组合：entry_band=.005、allocation.enabled=false、rebalance_band=.02、max_daily_turnover=1。原legacy不执行这些门槛；本轮明确其实际生效差异。单股止损与永久组合熔断不变，已修复完成止损状态。正常与双倍费用进入真实成交和优化器成本估计，因此路径可能不同。

优化器最小化协方差标准化跟踪误差+估计成本/波动尺度乘L1换手，不新增收益预测；不得买原信号不允许的股票、总仓不超过原目标、估计风险不超过原目标。求解失败使用原信号并记录。不会按当年收益调成本系数或门槛。

三池×两信号×三执行模式×两费用=36次。保存收益、回撤、换手、成交数、费用、实际平均股票仓位、优化失败数和净值。需区分省费用、减少风险敞口和真正净收益改善。股票池和年份多次查看，仅开发诊断；出现跨池正收益仍须冻结确认。任一失败不据此把亏损股票删除或任意改变门槛。
