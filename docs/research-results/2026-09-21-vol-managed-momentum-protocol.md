# 波动率管理的 12-1 月动量：冻结检验协议

本轮只检验一个文献型候选及两个预先指定的对照，不依据结果改参数：

- `equal`：相同股票池等权、同一波动率目标和执行层；
- `momentum12_1`：使用 `log(close[t-21] / close[t-252])` 排名，取前四分之一，按过去 63 个交易日协方差的边际波动率倒数分配，单股上限 20%，组合毛仓 95%，年化风险目标 10%；
- `momentum12_1_index_gate`：在上述动量仓位上增加等权股票池指数高于其 200 日均线的开关，关闭时保留现金。

信号在收盘形成、下一交易日执行，每 20 个交易日调仓；正常费用和费用翻倍各跑一次。窗口包括三个股票池的 2025-09—2026-09，以及随机股票池预先登记的 2022—2025 年度和连续窗口。指标同时报告收益、最大回撤、费用敏感性、逐股贡献和完整净值曲线。这里的年度窗口与先前研究存在数据重用，属于确认诊断，不是全新独立样本。

只有在所有股票池/时期均为正、费用翻倍仍为正，并且相对等权基线的同步区块 bootstrap 多重比较下界为正时，才考虑“跨池候选”。否则只记录失败或状态依赖，不能把单个窗口盈利解释为策略有效。
