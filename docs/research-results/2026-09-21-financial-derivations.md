# 财务信号数据补齐：受约束毛利润推导与债务歧义

## 实际进展

截至2025-09-01，50股中直接支持八项财务代理指标的公司由11家增加到19家。没有下载或合成价格，没有查看这些分数对应的后续交易利润；这是数据口径改进，不是策略成功。

新增可比公司由同份财报、同一期间收入减成本取得缺失毛利润。增发事项、非常项前利润的完整核验及历史全市场高BM资格仍未补齐，所以工具继续输出“证据不足”，不冒充完整Piotroski F-score。

## 推导约束

只接受CostOfRevenue或CostOfGoodsAndServicesSold的USD记录，与已按公开日期选定的年度收入记录同时满足accn、start、end一致；财报形式为10-K/10-K-A、提交日期严格早于判断日、成本非负。多个成本标签数值不同则拒绝推导。不使用旧的仅商品成本标签代替全部收入成本。

已有GrossProfit不覆盖。缺GrossProfit时，在内存副本中附加推导值和完整组件来源，原SEC缓存不改写；推导仍是财务代理口径，需在最终策略前审查会计可比性。

## 为什么没有直接填补长期债务

SEC的LongTermDebt标签在样本中不能仅靠名称认定为同一口径。Apple 2024年该标签96.662B等于非流动85.750B加流动10.912B；Qualcomm同份2024年财报中该标签13.270B等于其非流动标签，另有流动1.364B。Google也存在金额口径差异。因此不能统一把缺分项补成零，或用LongTermDebt机械替代“非流动+流动”。诊断保存原值和财报编号，不武断判定公司数据错误。

继续要求两项明确分项都有公开记录；若要扩大覆盖，应查阅债务附注并形成逐发行人可审计映射，而不是依据后续收益决定采用哪个标签。带租赁义务标签也未并入不含租赁的债务比较。

```bash
uv run --locked python scripts/audit_fscore_data.py   --symbol GILD --date 2025-09-01 --derive-gross-profit
```

单股输出包含derivation与收入/成本原始来源。GILD调用已确认启用推导后仍保留未知增发项和正式“证据不足”。全池审计执行audit_financial_derivations.py，结果为同名JSON。2项相关测试通过：修订/同日提交不可越界，以及推导拒绝混用财报或未来成本；184条推导的日期与组件财报/期间逐项检查通过。

这一步没有进行回报检验，不能把覆盖提升当作原目标完成。下一步仍需核验价值股资格和发行事项，再建立可比通过/未通过组，而非继续在缺失口径上直接选股。
