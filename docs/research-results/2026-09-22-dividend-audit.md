# 现金分红：数据可得性、权益时点与重复事件审计

本轮完成62股、1120条供应商现金分红记录的收集，尚未将其直接计入回测或信号。数据能补充历史账本，但不等于完整、当时可见的公司行动历史。总体策略研究目标未完成。

## 关键发现

1. 官方接口按process_date筛选，起止日期均包含端点。三个月分段已转换为互不重叠的包含区间，分页完整取回并按ID防冲突。请求2021-08-01至2026-09-22，却包含最早2021-07-08除息的记录，说明不能把处理窗口当除息窗口。
2. 1120条记录的process_date都晚于ex_date，间隔3至50自然日。process_date定义为Alpaca处理日，不是公告日、首次可见日或保证的入账日。官方也不保证创建及时性。不能根据这些当前快照声称交易前就已知全部分红。
3. 全部1120条没有显式currency；66条foreign/特别等事件需要额外核查。缺币种不能自动解释为USD，foreign也不能直接当作确定预扣税率。接口没有充分说明本批rate的税前/税后口径，普通股、外国发行人和特别分红不应直接混入同一净现金账本。
4. LIN在2023-03-13的1.275、支付日2023-03-28有两个事件ID，CUSIP分别G54950103与G5494J103。不能按ID不同直接支付两次，也不能未经身份/重组条款核验就删掉一条。需追踪历史证券身份。
5. 7只股票无返回记录，不能仅由此证明从未分红。即使查询至当前日期，近期除息、稍后支付/处理的事件仍可能遗漏。

## 发行人样例核验

取得Apple 2024-02-01第一季度业绩公告，确认普通股每股0.24美元、登记日2024-02-12、支付日2024-02-15，与供应商样例一致。该公告文本没有直接列出2月9日除息日，因此只确认金额、币种及上述日期，不虚构除息日原文证据。它也说明处理日晚于除息日不能被解释为市场直到处理日才获知分红。

[Apple公告](https://www.apple.com/newsroom/2024/02/apple-reports-first-quarter-results/)；[Alpaca接口文档](https://docs.alpaca.markets/reference/corporateactions-1)。字段定义、原文哈希和样例核验范围见dividend-source-evidence.json。

## 对策略适用性判断的影响

原价在除息日的机械下降可能扭曲价格动量、路径频次和止损；高分红股票的持有收益也可能被低估。但本审计没有量化之前每个账户的收益偏差，更不能据此宣称失败策略经修正就会成功。应先修复正确性，再保持原策略参数进行对照。

后续账本必须分开：除息前持仓获得权益，除息日确认应收，支付日才增加可用现金；除息日开盘才买入者通常不获得该次普通分红。即使期间卖出，已取得权益仍应保留。特别分红、due bill、税务/外汇/存托费需另行核验。信号总回报索引与真实成交价也必须分开，不能拿复权价直接执行整股交易。

## 可复现与核验

运行 `uv run --env-file .env --locked python scripts/audit_cash_dividends.py`，仅调用行情公司行动接口。已有缓存可复用；输出不包含凭证。原始分页响应保存在artifacts/research/dividend-audit，git中的审计JSON保留全部事件、问题标记和原始文件哈希。未调用真实账户或下单接口。

运行中核验62股票资格、每记录处理日期在请求段内、分页无循环、同ID无内容冲突；金额/日期/身份疑点归档而不静默修正。一般“没有数据=0”的处理在此处不可用。现有适用性判断仍须返回证据不足。
