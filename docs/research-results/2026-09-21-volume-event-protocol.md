# 异常成交活跃度：冻结协议

读取Gervais/Kaniel/Mingelgrin *The High-Volume Return Premium*原作Crossref摘要，DOI10.1111/0022-1082.00349。摘要提出异常高/低交易量后一个月收益差异，可能与可见度/需求有关。另检索结果首条是2013年后续论文，不能混同原作。未取得原文全文，本轮不是复现。

固定活跃度=close×volume/该日交易分钟数，是每分钟名义成交额近似，不是真实逐笔成交额；分母处理半日市。相较股数成交量，价格×股数在机械拆股理想条件下更稳定，但价格变化也会影响指标，不能称纯成交量效应。使用此前252日（不含当日）的95%/5%分位；超过95%触发high，低于5%触发low，全股票inverse_vol为基线。不附加价格方向过滤。分位点与21日事件资格事前固定，无参数搜索。

每股票每方向独立21交易日冷却，期间相同方向新事件不续期；另一方向独立，故两对照可能同时持股，是独立账户不应相互净额处理。资格i..i+20收盘，之后归零，最早下一开盘成交。三账户均只做多。活跃股逆波动归一化95%，20%单股截断不补足，63日LedoitWolf协方差缩放至10%估计年化风险。每天调整（1日），保留原分批/费用/止损/10%永久回撤停机。

7个已知窗口×3账户×2费用=42，涵盖3池2025→2026、random10三个单年及2022→2025连续；全部9月1日起止。此前已查看，只能开发诊断；不能用某一池成功或低仓位减亏当目标达成。全部保留并与相同引擎基线比较，未确认公司行动、股息总回报和存活偏差的边界继续保留。
