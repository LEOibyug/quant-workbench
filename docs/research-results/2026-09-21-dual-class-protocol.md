# 同发行人双股权相对价值：候选对象与第一道判别

在下载价格前固定5个配对：GOOG/GOOGL、FOX/FOXA、NWS/NWSA、UA/UAA、HEI/HEI.A。分别拟对应Alphabet、Fox、News Corp、Under Armour、HEICO。先通过SEC issuer CIK/tickers核验身份；当前ticker身份不证明全部历史法律条款相同。

经济假设：同发行人不同类别受共同企业现金流驱动，长期企业走势可能在相对价格中被部分抵消。但投票权、转换权、股息权和流动性溢价可使比价长期偏离1，不能简单等价套利。此轮仅研究候选，尚未核验逐股券源与历史法律条款，不得输出正式“适用”。

下载2024-03-01至2026-09-01原始SIP日线，5对均保留，不按价差收益筛选。逐日用此前126个已完成交易日对数价格比，拟合delta spread = a + b*lag spread，要求-1<b<0，半衰期2—63交易日，b的常规OLS t统计<-2，前后半样本平均比价偏移<=全窗1个标准差；两腿20日中位日成交额各>=1000万美元。观测z用当前收盘相对此前窗口，避免当日参与参数拟合。

-2不是严格单位根/协整检验临界值，滚动样本相关、OLS小样本偏差均需披露；不能用它冒充统计显著协整。这里是参数化风险筛选而非p值承诺。

候选入场需2<=|z|<=4，且偏离金额覆盖估计往返费用与半衰期持有的借券/分红准备金至少2倍。按每腿9500美元参照计算：价差/滑点合计单边3bps、佣金0.005美元/股最低1美元、卖出附加费0.3bps，short年费3%加2%分红准备金；有信号也不代表实际能借券。正式交易实验前需另固定同步两腿执行与退出协议。

本轮先报告两段年度逐对的规则通过率、信号次数（不是独立交易次数）、半衰期及期初判断依据。若无法通过先明确拒绝或缺证，不靠调门槛追求成交。适用性输出必须区分企业身份、价格机制、成本、券源及法律权利证据。

筛选完成后、查看P&L前固定交易附加规则：每对单独分配20000研究本金，合并曲线等于五个子账户之和，暂不跨对动态再分配；每腿最多账户47.5%，两腿同开同平，次日开盘，整数股按共同流动性限额缩放，两腿入场名义差额不超过2%。有持仓时不每日再平衡。前日平均分钟量1%仅用于保守准入：若需要的开仓量或平仓量无法全部成交，整对推迟，不制造单腿敞口；因此会暴露延迟退出风险。

固定入场均值/标准差，回到均值、偏离>=4个入场标准差、持有60交易日或筛选失效时退出；10%账户回撤禁止新开仓并请求退出。空头3%借券+2%分红准备金按自然日计提；正常/双倍成本，两年度与连续两年度共6个组合，所有失败对保留。子账户独立本金是本阶段简化，不能宣称已完成共享资金最优分配。实际券源/股息数据缺失仍限制实盘结论。
