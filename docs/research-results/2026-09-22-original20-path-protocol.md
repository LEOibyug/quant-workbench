# 原20股被动与交易路径诊断协议

固定原20股同一年，沿用原raw档案两费用配置。被动对照用每股相同初始美元预算，分别配置初始资本50%、100%，第一笔可执行日（策略档案第二交易日）开盘买入整数股，保留现金，不调仓、不止损，期末市值计价。按原引擎买入点差/滑点/佣金计算，检查成交量参与限制；另报与策略同公式的期末估计清算收益。无股息、无现金利息。50%/100%是固定暴露对照，不声称波动或beta完全匹配。

重新运行原策略正常费用，要求曲线/指标/贡献精确复现，保留实际成交。按每股从零建仓至回到零划分完整持仓阶段，最后未平阶段按期末收盘市值结算。阶段净利润=卖出收入−买入支出−佣金+期末残余市值，成交价已含冲击；不得再次扣冲击。归集所有20股所有阶段并核对逐股/总盈亏。报告ORCL/SOFI的全部阶段而非仅赢家，以及全部股票的阶段摘要。

这仍是观察过区间的解释诊断，不调参、不删股、不证明行业/企业前瞻适用性。被动与主动风控不同，不能仅凭收益差识别alpha。
