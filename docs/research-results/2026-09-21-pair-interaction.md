# 多股交易资格不能按单股贡献相加

38个完整账户完成，其中26个基线/单股账户与既有实验全部指标精确一致，12个双股账户为新诊断。按字典序预定三对：AAPL/AMD、AMZN/AVGO、BRK.B/COST；没有按收益选配对。

## 主要证据

2024—2025、释放资金重分配模式：完整账户收益-1.1454%；取消AAPL为-0.5106%；取消AMD为-0.0873%；同时取消两者为-3.9967%。单独移除的改善相加+1.6929个百分点，实际同时移除恶化-2.8513个百分点。差距4.5442个百分点，单股标签相加会得出相反的资格判断。

四个账户都在2025-04-04触发永久组合停机，因此不能解释为停机日期不同。触发日双股取消账户回撤12.0497%，完整账户10.7928%；双股账户最终最大回撤14.0047%。分配、持仓、成交和风险退出共同改变路径，本实验未隔离各机制，不能将全部交互归因于单一因素。

12个配对模式窗口中，净收益边际符号相对于单股之和有2例反转，效用符号有1例反转；这不是股票长期适用性证据。

## 核查与复现

运行 `uv run --locked python scripts/study_pair_interaction.py`。被取消股每日持仓为零且无成交；集合顺序对称、留现金、单股上限及全排除返回现金的合成检查通过。26个既有账户指标精确复现。完整结果（配置、信号目标、逐日资产、成交）保存在同名full.json.gz，停机日期审计单独存档。

公司行动未全面审计；同一原20股仅两年度、正常费用，不能代表其他池或双倍费用。账户均从现金起步，不解决现有持仓的状态依赖。已经使用的历史不作独立验证。

## 文献与下一步

读取Ghorbani与Zou（ICML 2019）Data Shapley: Equitable Valuation of Data for Machine Learning的PMLR原始摘要和题录：https://proceedings.mlr.press/v97/ghorbani19c.html 。文中讨论训练样本估值，提出Data Shapley并报告其与leave-one-out比较。本项目只借此提醒“单次删除不等于所有集合中的价值”，未读取全文、未复现该方法；摘要不能证明股票投资获利。

后续筛选应以整个可交易集合为决策对象，将协方差、约束、现有持仓及释放资金方式纳入评价。逐股模型可以产生候选，但不能按单股标签加总后发布；最终必须在同一共享账户中整体执行验证。本轮没有训练/发布新选择器，没有证明任何股票适用或总体目标达成。
