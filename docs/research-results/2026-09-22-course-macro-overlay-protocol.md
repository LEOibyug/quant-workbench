# 课件宏观判势叠加：固定方案与验证协议

本协议把 `ref/智能证券投资课件2026` 第3讲“股债金趋势/牛熊判势”、第7讲“策略制定—买卖规则—风险控制—策略执行”和第9讲“时间轴逐步递进”落实为一个可独立消融的日线候选。课件中提出的遗传、SVM、DTW和深度模型不在本轮直接采用：先检验可解释状态层是否提供增量。

已有仓库的 `index_gate` 是等权股票池指数高于200日均线时满仓、否则现金；其连续历史并未通过。本轮固定一个不同但不调参的连续覆盖：

* 股票池等权几何价格指数高于最近200个收盘的简单均线，`trend=1`，否则 `0`；
* 股票池中各股票当前收盘高于各自最近200日均线的比例为 `breadth`；
* 宏观仓位系数 `macro_scale = 0.25 + 0.75 × (trend + breadth) / 2`。因此双重牛市状态为1，双重弱势状态为0.25，中间状态按线性比例落在两者之间；
* 指数和广度只使用当前收盘及其之前的数据。前200日仅使用系数1预热，避免人为缩短样本；
* 系数只乘在已经完成的 fixed_ensemble 三专家目标之后，不改变股票排名、通道状态、残差反转、协方差风险缩放、单股上限或止损/熔断。

这不是股债金完整宏观模型：当前评价数据没有统一、同时点可审计的债券和黄金输入，因此明确称为股票池宏观代理。不是宏观因果识别，也不把课件示例收益移植到本项目。

验证固定六池：original20、alternate20、random10 的 2025-09-01≤日<2026-09-01；random10-temporal、transfer12-temporal、new12-temporal 的 2022-09-01≤日<2025-09-01。每池正常及双倍交易成本，分别使用 legacy 和已实现 banded 执行；共24个宏观账户，另保留24个同配置 fixed_ensemble 对照。窗口和股票池均为开发数据，不是独立确认。

运行前固定门槛：相对同一执行方式的 fixed_ensemble，在非 original20 的五池中，正常和双倍成本都至少4/5收益改善、收益差中位数为正，且回撤不能全部变差；否则不接入默认配置。即使通过，也只进入研究候选，不自动替换已发布策略。

检查：原 fixed_ensemble 对照两费用必须精确复现；宏观状态在数据前缀截断、输入行重排和价格单位整体缩放下保持一致；状态不读评价终点之后的数据；逐日现金、市值、盈亏和逐股贡献守恒；模型选择可在网页运行但默认关闭。
