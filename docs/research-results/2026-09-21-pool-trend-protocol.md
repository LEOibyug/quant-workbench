# 股票池整体趋势与总资金投入：固定协议

研究同一股票池的整体风险状态，区别于逐股择优。基础组合为95%等权、63日LedoitWolf协方差预测波动仅向下缩至年化10%，无杠杆。三个模式：equal基础；index_gate按池内每日等权再平衡无费用价格指数，当前指数高于含当前日200日简单均线则持基础目标，否则现金；breadth将基础目标乘“股票收盘价高于各自含当前日200日均线”的比例。没有个股选择，所有股同权，breadth不是只持均线上方股。

指数每日收益为全池个股收盘到收盘简单收益均值，从预热首日100开始累积。只用于已知市场状态，不把无费用指数收益冒充账户收益。所有信号收盘计算、下一开盘成交，每20交易日再平衡；状态在中间日变化不额外交易。固定200日而非按评价结果选择。不是严格自然月10月均线，也不是多资产股债轮动。

三已知池×三模式×两费用18次，修复后的原共享资金、分批、单股止损、组合永久熔断和费用保持不变。基础风险缩放后再乘状态，现金比例不能被归一化消除。报告覆盖率/状态开关/平均实际仓位，少亏不等同于更好选股。等权风险预算对照应和此前20日等权对应运行一致。

股票池和评价年多次查看，仅开发诊断。全池净正仍需冻结跨期确认；不因失败修改均线长度、门槛或股票名单。实际总仓和风险改变，因此策略收益差不是纯alpha。缺少股息/现金利息，不把现金存款收益作为成功来源。
