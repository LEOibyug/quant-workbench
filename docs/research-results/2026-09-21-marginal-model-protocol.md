# 执行层边际贡献回归：冻结协议

使用原20股票的2025-09之前历史。共同完整尾段，从第64日开始每21个交易日取一个决策时点t；账户在t收盘生成首个目标，t+1开盘开始成交，t+21收盘计价，结束不强制平仓。每个窗口账户重新以相同现金开始，窗口之间不继承持仓。因此标签针对从现金开始的部署决策，不代表持续持仓下的状态价值。

固定策略fixed_ensemble、5日调仓和已有费用/止损/分批规则。每窗口完整账户及20个逐股禁止交易账户；被禁止股票仍参与信号观察，只剔除成交。剩余正目标按原总目标比例放大、20%截断、同一63日协方差风险缩至10%，无机会留现金。标签ΔU=完整收益−禁止收益−0.5×(完整最大回撤−禁止最大回撤)，单位百分点。是模拟消融标签，不是现实因果效应，不可相加。

输入固定为64日分解的10个频谱/形态特征，加当前单股目标、全池目标总额、63日波动、相对于全池均值的beta，共14维。不含股票ID和未来数据。标准化+Ridge(alpha=10)，不调参；常数训练标签均值为基线。训练标签最后日期严格早于2024-09-01；验证窗口的整个64日特征区间不早于2024-09-01，且标签结束早于2025-09-01，其余样本丢弃。验证不决定超参数。每个日期组20股票相关，不能视作独立样本。

输出验证MSE、相关、按预测>0分组的真实边际效用均值、每日期组汇总与覆盖率；这些是标签诊断而非可实现组合收益。零权重股票也可能未来获得信号，标签保留全体。仅当诊断有希望才考虑完整账户；无论结果如何留档。数据与时期此前已用于研究，不能称全新独立确认。

所有窗口记录完整和消融账户指标，完整曲线本轮不存档（可由固定数据/配置/源码重算），避免误称保存了完整执行轨迹。生成每个日期组后保存检查点，禁止失败/中断后丢弃已有标签或重复启动相同活跃任务。
