# 财务改善适用性：Piotroski文献与数据可行性审计

## 本轮结论

已实现可调用的逐股、指定日期财务指标审计，但尚不能给出经过验证的股票适用判断，也没有启动一个口径不完整的“F-score回测”。50家公司中，38家进入预先设定的会计/身份可比候选范围，11家直接具备八项财务代理信号所需字段。第九项增发记录尚未完成可靠核验，因此完整九项评分没有交付。缺数据保留unknown，不作零分，也不把股数不增加等同于未增发。

## 文献实际说了什么

Joseph D. Piotroski，Value Investing: The Use of Historical Financial Statement Information to Separate Winners from Losers，Journal of Accounting Research (2000)，DOI10.2307/2672906。已取得Chicago Booth提供的PDF，阅读摘要、九项信号定义及样本形成部分；本地副本piotroski.pdf与文本位于artifacts/research/literature-2026-09-21。

论文先按此前财年全市场分布识别账面市值比最高五分位，再在其中使用财务强弱信号。其报告的优势主要集中在中小企业、低股票换手和缺少分析师覆盖的高BM公司。这提供一个明确的经济假设：对便宜、受关注较少、存在财务压力的企业，财务改善可能比静态“好公司”标签更有信息量。

不能把这个结论改写成“所有大盘股F-score高就适用”。当前50股多数为大型公司，缺全市场历史分位与历史分析师覆盖，尚不对应论文的候选总体。旧质量排序失败也不能据此反驳原论文的完整假设。论文历史收益不作为本项目的回测收益或完成证据。

## 可调用方法与口径

脚本audit_fscore_data.py的judge接受财报缓存、日期、股票和身份核验状态。只允许filed严格早于判断日的10-K/10-K-A；按当时可公开的版本挑选，财年相邻性与550日新鲜度检查。返回原始标签、财年、提交日期、金额、逐项真/假/未知，以及缺失项。

八项候选：利润为正、经营现金流为正、ROA改善、现金流高于利润、长期债务/平均资产下降、流动比率上升、毛利率上升、收入/期初资产周转率上升。长期债务要求非流动和流动分项都有记录，毛利润当前仅接受明确GrossProfit标签；未擅自把缺失债务解释成零或将不匹配收入成本相减。

NetIncomeLoss尚未逐份核验为原文非常项前利润，因此输出明确标记为GAAP代理指标，而不是原文完整F-score。score_lower/score_upper只表示该代理定义下未知项的分数区间，不是可信收益区间、概率或原文准确分数。增发现金流字段保留为观察证据，没有自动据此判定有/无发行。

会计不可比排除集继承此前预定义研究范围（金融、支付网络、REIT、公用事业等），不是依据此轮评分或收益选出。XOM因历史发行人身份未核验而排除。排除或缺数据均输出“证据不足”，不是企业不适用。

## 查询方式

```bash
uv run --locked python scripts/audit_fscore_data.py --symbol AMD --date 2025-09-01
```

返回逐项代理信号和提交日期来源，正式status仍为“证据不足”。未知股票返回缺缓存；省略symbol生成全池覆盖报告。该工具不需要密钥，不联网，不下载原始文件到Git。

1项针对性测试验证同日和后来提交的修订不会进入更早判断，以及缺标签不会自动填零；50份输出的来源filed日期均逐项确认早于判断日。没有进行交易收益筛选。

## 尚需完成的适用性证据

1. 对账面市值比资格使用历史全市场分布，或明确设计不同候选并重新验证，不能在这50股内部排序后冒充全市场最高五分位。
2. 核验毛利润/债务分项可替代标签、非常项利润口径和股权发行记录，避免字段覆盖本身决定选股。
3. 冻结资格与分数规则，在可比数据覆盖样本中对通过/未通过组的未来净效用进行验证，同时报告覆盖率、拒绝率和费用敏感性。

目前只完成文献到数据字段的可行性审计与判断入口，没有完成上述收益判别验证；原研究目标仍未完成。
