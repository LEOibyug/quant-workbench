# 短期与长期独立建模：统计策略探索（2026-09-18）

本轮完成独立短期与长期研究系统，并未证明可实盘盈利。短期统计候选均未建立净收益优势；长期趋势出现正收益，但低于高风险等权基准，收益集中、6月亏损、置信区间跨零。保持研究状态，不自动发布、不提交真实订单。

## 数据与审计更正

数据集 `bb9c03c89e0c4415b9b0f141eae22d65`：目录标记 Alpaca SIP，AAPL / AMD / NVDA / SOFI / TSLA，2026-03-02—2026-06-30，共163,800根分钟线、84个交易日。所有日期均已参与历史研究。各模型可以按历史时间因果训练，但这些结果不能称作全新样本外证据。没有新下载行情，也没有修改原始快照。

复核发现并修复两项影响旧结论的问题：

- 旧市场门控计算包含交易当日收盘价，属于前视偏差。现在只用前 N+1 个已完成日的收盘计算 N 个收益，并正确加入回测开始前的可用历史。原 walk-forward +1.57% 及相关尾部保护结论撤回。
- 旧分批执行将“继续持仓”当成继续加仓，可能超过预设批数；模型拒绝加仓还可能引起整仓退出。现在新增批次必须有明确加仓信号，持仓与加仓分离，按批独立退出、保留总风险退出。旧分批结果亦不可作为依据。

## 两套系统的边界

| 项目 | 短期分钟级系统 | 长期低频系统 |
| --- | --- | --- |
| 模型 | OU/AR(1)、Kalman、开盘贝叶斯对照 | 日线统计趋势、贝叶斯多日收益回归 |
| 时间尺度 | 分钟级观察，预测5–60分钟；开盘模型每天一次 | 历史20/40交易日、预测5交易日、每5交易日重新设目标 |
| 持仓 | 日内，尾盘清仓 | 可隔夜，跨日/跨周持仓，期末保留头寸按市值计价 |
| 分批 | OU偏离进一步增强时新增批次，最多2/3批；每批独立止盈止损/时间退出 | 单股目标上限20%，每日最多调整账户净值5%，目标股数固定至下次信号 |
| 风控 | ATR、日损失限制、冷却、参与率 | 波动率缩仓、单股10%止损、组合10%回撤熔断，优先撤销待买并减仓 |
| 资金 | 独立账户 | 独立账户，研究期间不与短期资金混用 |

当前只有分钟OHLCV，不支持验证盘口、订单队列、毫秒级高频优势。分批执行会增加最低佣金，不天然改善盈利。长期风险检查在开盘/收盘进行，非盘中实时止损，日终回撤不能与分钟级回撤直接等同。

## 长期独立账户：允许隔夜、低频分批

评估固定为4–6月，3月仅供可用历史；每个决策日只允许使用已经成熟的多日目标拟合回归，训练标准化亦限制在当时训练集。最多回看60个训练交易日，贝叶斯最少50个跨股票样本。没有把未来5日标签提前用于今天的拟合。

最终引擎 daily-position-v2：收盘设定目标股数，次日开盘按每日5%资金上限执行；达到计划股数后不因小幅价格变化每日再平衡。卖出先于买入，不借款；开盘跳空已触发风险阈值时先取消新增仓位。硬风险退出可超过5%分批限制，但仍受流动性约束。

费用同短期；期末收益包含未平仓市值，结果另给出估算平仓成本后的收益。未计现金利息、股息及公司行动总回报；检测到疑似拆股/极端跳变会拒绝跨日回测，不能据此声称所有公司行动均已处理。

以 **trend-w20-c0.5** 作为观察案例（非选定实盘配置）：4月+1.97%、5月+5.94%、6月−1.89%，总计+5.99%；2×费用仍为+5.28%。AMD贡献约$4,650，占总净盈利约78%；5日块自助法95%区间约[−3.13%, +17.02%]，包含亏损可能。9个固定长期对照均完整披露；这些区间未校正多重比较，也不是未来收益的置信保证。

日线贝叶斯模型未稳定优于简单趋势规则。当前证据支持保留长期趋势为后续观察候选，短期保持研究/持币，不把两套独立账户的收益直接相加。

## 使用与复现

统一启动仍为 `./scripts/start.sh`。研究页“短期实验”下可选统计策略/OU分批；“长期持仓”提供独立模型、日期、资金、预测跨度、调仓间隔、分批比例、持仓净值与CSV导出。长期任务及请求参数持久化，刷新可恢复上次任务。

```sh
uv run --extra neural python scripts/statistical_study.py \
  --dataset bb9c03c89e0c4415b9b0f141eae22d65 \
  --include-session --include-staged --output artifacts/studies/statistical-new
uv run --extra neural python scripts/position_study.py \
  --dataset bb9c03c89e0c4415b9b0f141eae22d65 --output artifacts/studies/position-new
```

完整本地结果分别在 `artifacts/studies/statistical-staged-2026-09-18/`、`artifacts/studies/position-v2-2026-09-18/`。精简度量与数据指纹已提交：[研究结果 JSON](2026-09-18-multihorizon-statistics.json)。测试覆盖当天收盘前视、成熟标签、分批数量上限、隔夜持仓/资金守恒、硬风险退出、任务进度及CSV。
