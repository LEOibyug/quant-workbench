# 组合下行半方差：运行前协议

读取Estrada《Mean-Semivariance Optimization: A Heuristic Approach》SSRN10.2139/ssrn.1028206原摘要（Crossref），未读正文。摘要指出组合半协方差依赖配置，不能直接将每只股票负收益截断得到的矩阵当作精确组合半方差。以下直接数值优化组合损失，不声称复现其启发式方法。

冻结63交易日简单收益，逐日减同滞后SOFR现金简单收益得X。下行目标为mean(min(Xw,0)^2)，上涨对照mean(max(Xw,0)^2)，普通对照为w'Σw（Σ为63日简单收益LedoitWolf协方差）。先形成组合收益再截断：资产之间的正负收益允许抵消。最小化上涨波动只是对称消融，不是新推荐策略。

三者共同约束sum(w)=min(.95,.2N)、0≤w≤.2，从等权初始化SLSQP，目标除以当期Σ对角均值做量纲归一化，增加1e-8×sum(w²)数值正则，ftol1e-10、maxiter500。使用解析梯度；失败直接报错停止，不偷偷以现金替换。之后都按同一Σ将股票仓位缩小至10%估计年波动，余款持币。这个风险目标不保证实际回撤或真实波动。

三历史池random10、旧transfer12、新12，连续2022-09-01至2025-09-01不含，273日预热。每20交易日决策，次日开盘原分批/整股/费用/单股止损/永久组合10%回撤停机，初始共享100000现金，统一SOFR动态利息。三方法两费用共18账户；不调收益门槛、不搜窗口或挑股票。不同目标权重但相同预先风险缩放，实际暴露与风险可能不同，须报告。

核验合成对冲先合计后截断、非负组合损失、解析梯度与中心差分、求解可行性/同一初始点目标不劣、真实历史前缀、资金守恒、18完整档案。报告收益/回撤/暴露/换手与现金对照；已看过的数据只作开发诊断，缺完整股息、SOFR非券商收益保证。即使全池正收益也不能以少参与或现金收益替代策略有效性确认，股票适用性仍需独立证据。
