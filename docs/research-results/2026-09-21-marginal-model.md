# 执行层边际贡献回归：训练与验证

结论：该候选未通过标签预测验证。回归MSE 0.15289劣于常数基线0.14626，相关系数−0.09282；预测正组实际效用−0.03863百分点，非正组+0.02656百分点。不得将此输出用作自动交易资格；下一步不能仅继续调整阈值寻优。

本轮构造按时间成熟的组合消融标签并训练一个固定Ridge模型。标签为模拟器中的边际效用，不是盈利概率；预测正值不等于股票已验证适用。未运行模型驱动的实际账户，不能把标签选择均值当可实现收益。

## 样本和隔离

训练41日期组、820股票窗口；验证8日期组、160股票窗口。训练最后标签日期2024-08-05；验证最早特征窗口起点2024-09-04，最后标签日期2025-08-07。每组21个实际账户，总计1029个账户。

每21交易日采样，标签覆盖t收盘到t+21收盘，边界相邻；同组股票相关，不视作独立样本。标准化只在训练集拟合，Ridge alpha=10，没有依据验证选择参数。此前研究已查看这些时段，仍只作开发诊断。

## 调用与限制

```bash
uv run --locked python scripts/judge_marginal_model.py --symbol AAPL --date 2025-09-01 --prices artifacts/research/annual-momentum/original20.parquet
```

输出股票池、信号日、候选边际效用及证据不足状态。模型只允许2025-09及之后的查询，检查模型哈希、共同交易日与行情陈旧。每个窗口从现金开始，不能解释成当前任意持仓状态的边际价值。标签末日按收盘市值计价、不强制平仓，不包含最终假设平仓费用；与连续运行账户的目标也仍存在差别。

训练样本使用固定ensemble，对单股取消资格后按比例重分配，单股上限和协方差风险缩放仍保留。改变基础策略、股票池、执行方式或风险偏好会改变标签。禁止交易的股票仍参与观察池信号构建，不等于从研究股票池移除。

检查点保存逐账户指标，没有保存全部成交轨迹，不能称完整执行档案。源数据SHA与配置包含在标签文件，模型哈希在训练报告。运行内逐账户检查被禁止股票每日零持仓。训练与验证时间边界及特征数核查通过。总体策略有效性和企业适用性仍未确认。
