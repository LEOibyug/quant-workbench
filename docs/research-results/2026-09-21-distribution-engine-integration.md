# 分拆权益进入日线研究引擎

已将研究分拆权益接入 `simulate_positions(..., daily_bars=True, research_distributions=book)`，仅允许日线legacy执行；启用组合allocation或cost-aware会拒绝，避免尚未定义附属资产订单语义时混入其他账本。

固定政策：

- 事件必须已核实、母股在策略股票池、子股不是策略候选；事件ID重复拒绝。
- 分拆日开盘风险检查前，根据母股/子股同期开盘价分摊母股basis；母股原持股数不变，整股子股和零股应收登记在独立side book。
- 子股附属资产持有至研究期末，不自动进入策略信号、排序、分配或母股止损；组合永久停机也不卖出附属资产。
- 零股未取得真实净结算现金前不是可用现金；side book只接受精确日期open/close报价，缺价不前填。
- 现金余额只反映真实交易现金；组合权益和开盘风险包含附属资产市值，收盘浮盈亏包含附属资产未实现损益。
- 分拆日取消母股旧数量目标，避免在basis转换前执行机械除权订单；随后收盘信号可以生成下一个调仓目标。
- 期末side asset仍未按真实清算成本估值，`estimated_liquidation_return_pct`返回None；报告必须保留该限制。

新增接口记录 `research_distributions.events` 和政策，curve额外写入 `distributed_assets`。母股contributions暂把附属资产最终市值归到母股，用于研究账本总量核对，不是最终产品会计归属；需要子股独立贡献、交易和税基后才能用于展示。

构造测试：母股100→80、1/4子股80，配置2%单股/组合止损。未经权益的原账户停机，启用权益后不错误停机；每个收盘点现金+母股市值+side asset市值等于equity，equity−初始资金等于已实现+未实现损益，现金没有凭空增加。全仓库185个测试通过。

这是研究接口，不是完整公司行动系统：尚未处理股息、拆股、反向拆股、并购换股、真实零股清算、清算费用、税基、子股流动性、事件资格的记录日与卖出例外、strategy展示贡献拆分。备用20历史需先把GEHC/GEV/KD事件和其它公司行动纳入同一账本，不能直接以原始价格运行。没有策略收益或适用性成功声明。
