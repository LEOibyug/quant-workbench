# 共享资金、组合分配与轮换：实现与历史检验

日期：2026-09-18。已实现研究与展示流程，未接入券商下单。**这是独立的资金管理层，不是已经证明盈利的新预测模型。**

## 方法选择与检索依据

实际阅读的主要资料：

1. [Boyd 等，Multi-Period Trading via Convex Optimization，2017](https://web.stanford.edu/~boyd/papers/cvx_portfolio.html)：把预期收益、风险、交易成本和持有成本纳入统一优化。作者明确说明，框架本身不解决未来收益预测问题。
2. [CVXPortfolio 的单期优化策略](https://www.cvxportfolio.com/en/stable/optimization_policies.html)：收益预测、协方差风险、交易成本及约束分开组合。
3. [CVXPortfolio 成本模型](https://www.cvxportfolio.com/en/stable/costs.html)：优化使用的成本近似与模拟成交成本应明确区分。
4. [scikit-learn 协方差估计文档](https://scikit-learn.org/stable/modules/covariance.html)：小样本经验协方差容易不稳定，Ledoit–Wolf 收缩估计改善数值稳定性。

选择“收缩协方差 + 单期风险/成本优化 + 调仓缓冲带”，不直接照搬全套多期优化。现有股票只有5只，预测优势尚不稳定；增加复杂未来路径假设并没有相应证据支持。等权、单纯追涨排名和逆波动率容易忽略换仓成本或相关性；HRP 可作为后续对照，目前没有必要仅为5只股票增加聚类结构。

## 与原策略共同作用

流程是：**原策略/模型确定可买、可持有、必须退出 → 组合层确定各股目标权重 → 共享资金执行器分批成交。**

- 分配层不绕过原策略的入场资格。模型拒绝入场时，即使预测分数很高也不能被优化器重新放行。
- 长期趋势、贝叶斯回归、无预测模型的等权规则均可叠加。无收益预测时只做风险与成本分配，不凭空制造收益预测。
- 短期仍逐分钟运行原规则与可选时序模型，分配层默认每30分钟重算目标；收盘前必须清仓。
- 可以指定参与轮换的股票子集；其他股票保留原目标，并占用同一个组合账户的资金。空子集表示全部参与。
- 关闭开关仍使用原流程。旧发布版本不会自动获得新资金管理参数，需在开发页重新验证并发布。

### 分配器

在已允许持有的股票中，以预测收益/波动率及持仓成本缓冲进行排名，选取最多K只。没有预测时偏向较低波动，并给已有持仓一个避免无谓换仓的成本缓冲。**这一步是启发式筛选，不声称求得全局最优持仓数量组合。**

对选定股票，求解：

```
min  风险系数 / 2 × w'Σw − μ'w + 成本惩罚 × Σ cost_i × |w_i − current_i|
s.t. 0 ≤ w_i ≤ 组合单股上限
     Σw_i = 本轮策略许可的资金预算
```

Σ使用截至决策时刻已完成收益的Ledoit–Wolf估计，至少20个观测，最多使用配置窗口。收益和协方差换算到同一预测跨度。预算不超过原策略许可的总敞口、选定股票的容量及现金缓冲后的可用空间；未加入轮换的股票先预留原目标。优化失败则不新增风险，只保留仍符合条件且经限额裁剪的持仓，并记录 `fallback_hold`。

优化中的最低佣金使用计划仓位估算，实际成交重新精确扣费。现金缓冲和单股上限约束的是决策时目标，价格漂移、跳空、手续费和未成交可能使实际比例不同，因此页面同时显示目标与实际权重。

### 执行与优先级

- 短期新增同步分钟执行器，所有股票共享一份现金账本；不再先独立跑完A股票再跑B股票。
- 同一时点先执行卖单，随后用已释放现金按比例缩减买单，避免买单按股票名称争抢资金。
- 常规成交受每日成交总额预算和成交量参与率限制；日预算按买卖两边成交额累计。例如买入50%净值再卖出50%计100%。
- 常规小幅调仓使用净值比例缓冲带。止损、日损保护、原规则退出及日内尾盘清仓不应被分配器阻止；风险退出仍受流动性约束。长期原规则的普通减仓仍遵守分批计划。
- 分批策略的批次账本会同步扣减组合轮换卖出的数量，防止之后重复卖出已减持的批次。
- 长期成本、流动性和隔夜风控沿用原引擎；日线模式仍明确使用前日总量/交易分钟数作为估算，不能当作实际开盘可成交量。

## 默认研究配置

| 参数 | 长期 | 短期 |
|---|---:|---:|
| 风险估计最大窗口 | 60交易日 | 60分钟，同日收益 |
| 分配间隔 | 原长期调仓间隔，默认5交易日 | 30分钟 |
| 轮换池目标持有数 | 最多3只 | 最多3只 |
| 组合单股目标上限 | 35% | 35% |
| 目标现金缓冲 | 5% | 5% |
| 风险惩罚系数 / 成本惩罚倍数 | 10 / 2 | 10 / 2 |
| 小额调仓缓冲 | 净值2% | 净值2% |
| 每日常规成交总额 / 净值 | 20% | 100% |

这些是事先固定的研究参数，不是通过下面区间寻找的最优参数。35%允许比原20%上限更集中，因而收益比较不是等风险比较。

## 固定参数真实数据对照

数据：既有 Alpaca SIP 原始分钟快照，AAPL、AMD、NVDA、SOFI、TSLA。2025年长期评估3月3日至10月30日、短期9月1日至10月30日；2026年均评估4月1日至6月30日，结束日期右端不含。两个区间均已参与研究，**不是新保留样本**。

资金均10万美元。价差2bps、单边滑点2bps、佣金每股0.005美元/最低1美元、卖出规费0.3bps、参与率1%。固定2种长期模型、2种短期规则，每个分别开/关分配与1×/2×成本，共32个对照，全部保留。短期本轮不叠加时序预测模型，避免把预测变化与分配变化混在一起。

| 周期 / 策略 | 区间 | 原流程收益 | 开启分配收益 | 原回撤 → 新回撤 |
|---|---|---:|---:|---:|
| 长期趋势 | 2025年3—10月 | +8.93% | +11.39% | 2.21% → 2.81% |
| 长期趋势 | 2026年4—6月 | +5.99% | +13.50% | 2.54% → 4.41% |
| 长期等权 | 2025年3—10月 | −8.55% | −10.21% | 11.66% → 12.65% |
| 长期等权 | 2026年4—6月 | +25.34% | +7.00% | 10.19% → 10.64% |
| 短期双均线 | 2025年9—10月 | −31.65% | −1.47% | 31.86% → 1.59% |
| 短期双均线 | 2026年4—6月 | −42.97% | −3.87% | 44.50% → 4.62% |
| 短期状态组合 | 2025年9—10月 | −3.82% | −0.63% | 4.44% → 0.89% |
| 短期状态组合 | 2026年4—6月 | −5.66% | −0.71% | 6.14% → 0.91% |

长期为日终回撤，短期为分钟回撤，不能直接横向混比。

长期趋势的两段区间在双倍成本下为+9.41%和+12.26%。但是2026年组合约13,498美元净利润中，AMD贡献约14,027美元，其他股票合计亏损，**改善主要伴随集中在单一赢家，不能当作分散化优势或稳定超额收益**。2025年SOFI贡献约57%利润。

短期状态组合的平均现金约99.4%—99.5%，开启后主要减少了敞口和交易；更小的亏损并不等于更好的预测。双倍成本仍为负收益。无预测的长期等权叠加分配没有改善两段结果，因此不建议无差别给所有策略开启。

本轮可行结论：该机制能正确执行跨股票资金共享和轮换，长期趋势可保留为后续固定参数观察候选；尚不能称为稳定有效的实盘自动交易系统。后续应使用未参与设计的新时期，比较相同风险/敞口预算的对照，检查集中度与成交成本，不继续用已看过的区间调到盈利。

结果：[全部32组精简数据](2026-09-18-portfolio-allocation.json)。本机完整过程在 `artifacts/studies/portfolio-allocation-2026-09-18/run-v2/`。v1为执行预算比例分配修正前的检查版本，不作为最终报告依据。

## 展示与验证

长期与启用组合层的短期共享详细复盘组件：净值、现金、回撤、已实现/浮动盈亏、日收益、各股实际/目标比例、各股价格/成交量/持仓、模型输出、逐笔成交及CSV。长期日线图表不会伪装成分钟细节；蓝线为该周期收盘价，标记为真实模拟成交价。买入/卖出标记仅绿色/红色圆点，保留悬浮和键盘可访问的详情。

旧长期任务没有逐股曲线，页面提示重新运行；不根据期末持仓反推历史仓位。详细回放按游标截断成交，尚未发生的成交不会提前出现。份额图含现金，实际占比合计100%。完整资金/逐股持仓CSV不做图形抽样；屏幕曲线抽样以控制绘制量。

验证包括：资金/市值守恒、已实现与浮动盈亏对账、跨股票同时持有和换仓、未来行情扰动不改变历史结果、模型否决优先、冻结发布后独立获取选定股票行情、明细导出，以及浏览器的长期配置/发布与两类组合回放。
