# 低资产扩张策略的启动日期敏感性

上一轮22股三个年度分别盈利而连续三年亏损，不能把年度拼接当连续能力。本轮固定同一22股、相同低增长三分组与全部资金/风险参数、终点2025-09-01，只改变账户启动日：2022-09-01起最初20个实际交易日，正常/双倍费用，共40完整账户。提前冻结，全部保留，不挑最佳启动日。

每次从100000现金开始，用此前273交易日预热；每20交易日从该启动日重新安排决策，这是当前引擎的实际行为。起点变动同时影响初始成交、持仓路径、调仓相位与风险停机，因此这是部署起点敏感性，不是隔离调仓相位的因果实验。观察长度相差最多19交易日，终点相同，不当作等长独立样本。

输出每账户收益、回撤、费用、换手、持仓贡献、首次停机日期；报告全体范围、中位数、亏损/停机数量和两费用对照，不搜索门槛、不删失败日期、不以中位数正就声称策略成立。第一个日期两费用应精确复现上一轮连续结果。日期高度重叠，不计算假独立p值。

还没有完整分红/公司行动且数据曾反复研究，结果只能诊断稳定性；启动日变化不能用来给股票事后贴适用标签。协议不授权改变生产默认或自动关闭风控。
