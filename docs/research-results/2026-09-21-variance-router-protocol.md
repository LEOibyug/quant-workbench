# 异方差稳健方差比路由：实验前固定协议

核查Lo–MacKinlay，NBER WP2168原摘要：其随机游走拒绝不能直接解释为价格平稳均值回归。此处仅检验收益聚合方差的偏离，不宣称价格平稳、未来盈利或企业永久适用。

固定126个日对数收益、聚合q=5。单期样本方差=sum((r-mean)^2)/(n-1)，q期重叠和去q*mean后平方和除以q*(n-q+1)*(1-q/n)。VR为二者比。异方差稳健渐近方差theta=sum_j[2(q-j)/q]^2*sum_t(e_t²e_{t-j}²)/(sum e²)^2，j=1..q-1；z=(VR-1)/sqrt(theta)。不多尺度挑最大统计量。双侧5%阈值±1.96：高端选择通道趋势、低端选择残差反转、中间现金。零方差/不足126条有效收益给证据不足并现金。该渐近检验小样本可能失准，滚动重复检验未校正，不将单次拒绝当作验证结论。

三模式：vr_router按逐股判定选择原专家；ungated均分通道/残差原专家目标；gross_equal将路由当时目标总仓等分全部股。路由/ungated均复用原专家已经风险缩放的目标，再约束单股20%、总仓95%、年化预测波动10%；gross_equal为目标总仓匹配，实际风险和成交后仓位未必相等。

原三个池×三模式×两费用=18次，采用修复只多共享资金引擎、5日调仓、原风控/分批/成本。使用年度预热清单，全评价期有126收益。记录判定比例，若几乎全部现金不可当作策略成功。参数不按评价结果选择。池和年份已反复查看，开发诊断非独立检验。适用性正式状态保持证据不足，候选分类单列；若账户结果支持，还须进一步独立确认。
