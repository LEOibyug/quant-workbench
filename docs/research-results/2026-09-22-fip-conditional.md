# 连续信息：控制涨幅与波动后的预测增量

结论：尚无可靠增量证据，不进入账户回测或发布。增强模型在历史评估期误差变大、最新期仅微小下降；两期都劣于零预测基线。结果不能支持“连续上涨的股票适用动量”的判断，也不据此反向挑选离散上涨股票。

## 固定方法

协议在运行前以b0d0408提交。历史为随机10与新增12的22股，最新为四池合并62股。先按交易日对齐，再每20日观察，只取形成期动量为正且当日不少于10只候选的日期。训练截止2024-09-01，最后训练标签终点为2024-08-30。输入仅使用决策收盘前可知价格；标签从次日开盘到其后20交易日开盘，扣除同日期候选均值。

基础Ridge控制形成期对数涨幅、其平方、63日对数波动率和21日近期涨幅；增强模型加入−ID。各特征按当日横截面标准化，每日期总训练权重为1，alpha=10、无截距、不调参。标签均值是事后评价量，不是模型输入或交易时已知值。本检验衡量固定线性模型的预测增量，不识别因果效应或全部非线性关系。

训练样本173条、仅13个日期组。训练时点覆盖有限，不能将173只股票日期记录解释为173个独立时间样本。模型连续性系数为-0.00099627，与候选正方向相反，但该拟合结果不构成反向交易证据。

## 覆盖与限制

历史38个计划日期中25个合格，最新13个中12个合格。剩余因不足10只正动量股票或标签终点越界被排除，完整原因见JSON。训练/评估间跨界标签从训练排除，不让未来结果污染训练。

原价不含完整公司行动和总回报，当前成分存在生存者偏差。模型没有估计真实费用后的单股组合边际价值；即使毛相对收益预测改善也不能等同净交易盈利。增加控制变量亦不保证已清除所有混淆。本轮未改动网页或现行策略。

## 核验与复现

运行 `uv run --locked python scripts/study_fip_conditional.py`。真实数据前缀截断后所有已成熟特征及标签完全一致；训练末次标签严格早于首个评估决策；所有条目的形成期、决策、进出时点顺序核验通过。JSON保存来源文件哈希、模型全部系数、逐日期误差、覆盖和区块区间；panel.json保存全部原始/标准化输入及标签。

研究目标仍未完成。此结果帮助排除将简单路径频次直接升级为适用性结论的做法，并未证明所有信息连续性模型都无效。
