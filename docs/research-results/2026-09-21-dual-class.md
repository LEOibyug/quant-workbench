# 同发行人双股权配对：候选筛选与交易实验未通过

本轮换用相对价值机制，不再预测企业股票整体上涨。固定五个同发行人配对，先核验身份，再评估相对价格的可交易性。结论：**共同发行人关系和参数化价差回归条件不足以构成盈利策略**；正常费用的五对组合连续两年仍亏损，不把个别盈利对事后挑选为“适用”。

## 经济关系与可判别条件

| 配对 | SEC核验发行人 | CIK |
|---|---|---:|
| GOOG / GOOGL | Alphabet Inc. | 1652044 |
| FOX / FOXA | Fox Corp | 1754301 |
| NWS / NWSA | NEWS CORP | 1564708 |
| UA / UAA | Under Armour, Inc. | 1336917 |
| HEI / HEI.A | HEICO CORP | 46619 |

身份来自SEC submissions的当前tickers字段，已核验两类股票同一CIK；这不是历史股权法律条款审计，未证明投票、转换、股息或流动性权利相同。因此不能把比价应为1当作无风险套利依据，未核验券源可得性也禁止宣称可直接实盘。

Gatev、Goetzmann与Rouwenhorst，NBER WP7032（1999，RFS 2006）原站摘要已读：https://www.nber.org/papers/w7032 。该研究根据历史标准化价格距离配对，并讨论微观结构影响；本研究的同发行人对象与参数筛选不是对原论文的完整复现，不能移植其历史年化收益结论。

判断原型对每对股票、每个收盘日期，只用此前126个完整交易日的log(A/B)回归delta spread=a+b*lag spread。检查-1<b<0、半衰期2—63日、OLS t<-2、前后半窗均值偏移不超过1个标准差，以及每腿前20日中位成交额>=1000万美元。t<-2不是单位根检验临界值，不能声称已经统计证明协整。

通过后还需2<=|z|<=4，偏离覆盖估计往返费及半衰期持有的借券/分红准备金至少两倍。各条数值、理由和窗口日期在筛选JSON中；即使规则通过，正式status仍为证据不足，原因是盈利验证、券源和历史股权条款未满足。

## 交易模型

每对研究本金20000美元，五对合计100000；本轮没有跨对动态再分配，不能声称优化了共享资金。每腿最多对应子账户47.5%净值，两腿按共同流动性上限缩小，整数股入场名义差不超过2%，次日开盘同步成交。先前日总成交量/交易分钟数×1%作为保守流动性代理；无法完整开平一对时推迟，不构造单腿成交。这个全成或不成模型不是实际券商保证，存在延迟退出风险。

入场后固定当时价差均值和标准差；回到均值、偏离达到4倍入场标准差、持有60日或筛选失效则请求次日退出。子账户10%回撤触发停止新开仓并请求退出。没有逐日再平衡。

价格冲击单边3bps、每股佣金0.005美元最低1美元、卖出附加费0.3bps；short年费3%加2%分红补偿准备金，按自然日扣除，双倍成本全部加倍。未计多头实际股息、实际short股息及实际券源报价，因此不是完整总回报。保守准备金也不能保证覆盖高借券费或召回。

NWS/NWSA在连续两年内盈利，但只有两次开仓，不足以建立独立有效性；不能把它单独保留就宣称找到了适用公司。连续结果与分年结果交易次数可不同，因为子账户仓位跨年延续、风险预算及信号状态不重置，且两个年度评价互有重叠，不算独立6个样本。

交易密度低、参与率约束限制名义投入，因此小回撤不意味着强大的套利能力。若放宽条件或提高杠杆需要新协议，不能隐去本轮失败后只展示调参后的结果。

## 核验与下一步边界

三项针对性测试涵盖未来数据不影响当时筛选、交换两腿后z对称与半衰期一致、历史不足/固定价差不发信号、同步账本在构造回归价差中盈利且双倍成本降低收益、缺流动性时不开单腿仓。全部原始交易结果逐对账本自检，五对期末权益与组合汇总一致。生产网页未改。

本轮未满足持续研究目标，也未形成可正式输出“适用”的企业判断法。经济身份是一种可事前验证的必要条件，但不能代替统计稳定、成本空间和真实执行条件，尤其不能将历史两次盈利当作适用性证据。
