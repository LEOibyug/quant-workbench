# 入场稀疏、模型改进与三组佣金对照

查询与评估日期：2026-09-18。结论：佣金明显影响净收益，但本次旧模型几乎不交易的主要原因是概率门槛。新组合改善了成交覆盖，尚未证明稳定的扣费盈利能力。

## 官方佣金核实

以下是美股普通整股交易，金额为美元；行情 API 供应商不等于交易券商。

| 情景 | 基础佣金 | 最低佣金 | 适用限制 |
|---|---:|---:|---|
| Alpaca 自主交易免佣情景 | 0 | 0 | 符合免佣的零售订单流；合作方、Elite Smart Router、非零售订单流可能收费 |
| IBKR Pro Tiered 首档 | 每股 0.0035 | 每订单 0.35 | 月成交股数 ≤300,000；额外交易所、清算和转收费；通常每单佣金上限为成交金额的1% |

官方依据：

- [Alpaca 佣金说明](https://alpaca.markets/support/commission-clearing-fees)。
- [Alpaca Brokerage Fee Schedule](https://files.alpaca.markets/disclosures/library/BrokFeeSched.pdf)，第1—4页：佣金例外、Elite路由费、股票监管费及日终汇总取整。
- [Alpaca 非零售订单流说明](https://alpaca.markets/support/what-flags-an-account-as-non-retail-and-what-are-the-implications-of-being-flagged)：高撤单比例、快速报撤单等可能触发审核；仅凭使用分钟策略不能判断账户必然免佣或必然收费。该说明标注2022年11月，当前费表仍列出非零售例外。
- [IBKR 股票佣金表](https://www.interactivebrokers.com/en/pricing/commissions-stocks.php)：美国区域、首档、每单最低/最高、第三方费用及注释。Lite免佣有美国居民等条件，未用它替代Pro方案。

当前两家费表均列出股票卖出的SEC费：成交金额 × 0.0000206（每百万美元20.60美元，即0.206bps）；FINRA TAF为卖出每股0.000195美元，Alpaca列明每笔上限9.79美元；CAT为买卖两边每股0.000003美元。Alpaca按每个费用类别在账户日终汇总后向上取整到美分。IBKR还列出NSCC/DTC每股0.00020美元，交易所费用因路由、订单类型及流动性而异。

这些是查询时的现行费率，不能直接冒充2025年历史账单。当前回测只有通用卖出规费bps，尚未逐项实现有生效日期的SEC/TAF/CAT、订单上限与日终取整。本轮因此做**基础佣金敏感性对照**：三组均使用同一卖出规费近似0.3bps，不把未实现的第三方费说成已精确纳入。IBKR一组不含上述额外费用，不能作为完整成本报价。

项目的最低佣金目前按每次成交收取；券商通常按订单累计，单个卖出订单跨多个分钟部分成交时，本项目可能高估最低佣金。当前新组合三组对照均为每笔完整买卖各一次成交，因此该差异没有改变这组结果。没有对不同费用方案假设不同的路由成交质量。

## 同一行情与模型的对照

- 数据：Alpaca SIP真实分钟行情，AAPL / AMD / NVDA / SOFI / TSLA。
- 开发：2025-02-18至2025-04-21之前；验证：2025-04-21至2025-05-09之前，共14个交易日。
- 初始资金100,000美元，五股独立等额资金。只做多、无杠杆、无隔夜。
- 三组都保留完整价差2bps、每边滑点2bps、卖出规费近似0.3bps。
- 每种佣金都重新模拟数量、规则成本门槛、模型成本判断和资金路径，不是固定成交记录直接加回佣金。
- 本轮没有运行最终测试。系统已标记重叠日期存在过去的测试暴露，以下属于探索性研究，不能当作全新未见样本的证明。

旧严格模型换佣金仍为3笔：1250个规则候选分钟中，57个模型预热、1190个预测概率低于0.55，只放行3个。该旧实验的模型收益成本硬过滤是关闭的，因此不能将1190次概率拦截归咎于佣金；规则自身仍检查成本。

新组合保守情景中，实际成交路径扣除建模成本前盈利998.43美元，费用600.15美元，点差/滑点928.60美元，合计后亏损530.32美元。免佣情景虽略有盈利，但14天仅30.17美元，新增少量滑点便可能抹去，不能据此选择为已验证盈利策略。

以1000美元仓位、10股×100美元、一次买入一次卖出且价格不变为例：上述统一执行假设下，保守情景往返成本约26.3bps，IBKR基础情景约13.3bps，免佣情景约6.3bps。此例不含未建模第三方费；小仓位受最低佣金的影响尤其明显。

## 本次规则与模型改动

实现见[入场融合说明](../entry-fusion.md)：新增局部成交量加权均价回归与趋势恢复规则；GRU收益头按开发期统计量标准化；新增模型调节规则仓位的模式，保留明显不利预测否决、预热和实际成交价成本复核。原严格模式与旧模型兼容逻辑保留。没有最低成交配额。

新GRU仍是因果卷积＋双尺度GRU＋注意力，60,548参数，使用已成熟预测/GT/误差反馈与在线更新。本次k=30、预测跨度5分钟，训练和实际逐分钟验证使用MPS。归一化尺度30.9265bps仅由教师训练段计算。仍支持CUDA→MPS→CPU自动设备选择。

严格模式两行的成本开关不同，不能据此把新模型零交易完全归因于收益标准化。固定新规则和仓位调节方式后，标准化模型相对旧模型将亏损从606.30减至530.32美元，但未扭转净亏损。其Brier从0.251012改善为0.250619，仍差于常数基线0.250107；收益MAE从18.2139改善至18.1508bps，仍差于零收益基线18.0874bps。尚未证明可交易的预测优势。
