# 市场调整年度动量：固定实验协议

候选动机为剔除共同市场贡献后的个股持续表现。本轮不宣称复现Blitz等文献残差动量的三年多因子估计。使用已有年度预热，只估计过去252日同池等权对数收益因子和股票回归斜率beta，回归包含截距。

重要代数约束：不能把同252日含截距回归的去均值残差直接求和称为年度alpha，因为全窗口残差和必为零。故明确定义市场调整收益u=r-beta*market，保留截距部分；评分=sum(u前231日)/(std(u前231日)*sqrt(231))，跳过最近21收益，不把零和残差导致的末月反向值冒充年度延续。beta估计包括当前已知252日，所有信息都在决策收盘可用。这是市场调整动量，非纯OLS残差动量。

固定三个模式：adjusted上述标准化评分；raw原12-1月累计收益；equal等权。前两者选择前25%（向上取整），逆63日波动分配95%、逐股上限20%截断不再分配，再以63日收缩协方差将预测年化波动向下缩至10%。等权同总预算与风险缩放。没有事后绝对动量门槛，无做空，无额外公司筛选。

每20交易日调仓，采用修复后的原共享资金/分批/止损/永久熔断引擎。三已知池×三模式×正常/双倍费用18次，全部保存。raw/equal应复现年度动量已有同配置结果，作为实现交叉核验。若候选全池为正，必须再冻结跨时期确认。股票池和时期反复查看，只能作开发诊断；不因看见结果改方向、窗口或因子。
