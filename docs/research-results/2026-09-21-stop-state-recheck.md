# 单股止损状态问题：修复与46次重验

## 根因与明确语义

旧代码在日终先计算新目标，再仅在“空仓且目标为零”时解除forced_exit。每日调仓若一直给正目标，即使已完成止损清仓，标志也可能一直保持；同一股票5日调仓能在非调仓日解除。于是每日调仓会意外变成对部分止损股票的永久禁入，影响资金和收益路径。

合成恒定目标例在修复前确实失败：每日止损清仓后无后续买入，而5日允许重入。该缺陷与真实股票涨跌无关，足以独立证明需要修复。

现固定为：单股风险退出保持到实际持仓清零，收盘处理新目标之前解除该单股标志；新信号最早下一开盘成交。部分退出期间不补仓；组合永久熔断独立保留。不修改任何策略参数、止损阈值或成交费用，也不引入因评价收益选出的冷却期。

4项专门用例覆盖每日/5日清仓后重入、部分清仓继续退出、组合熔断永久有效；加原position及daily_strategies回归，共31个不同用例通过。修复前后因果特性和账本回归通过。历史报告保留旧值并补充引擎提醒，不能把旧日频优势继续当作策略证据。
