# 条件适用性候选 v0：执行前固定协议

目的：判断事前财务与价格状态门控是否能改善现有fixed_ensemble在全部三个股票池的表现。已知股票池仅用于开发诊断，不算独立验证。选择两个机制清楚的固定候选，不做参数搜索，不以已知收益挑选通过股票。

价格条件：126个交易日收盘价均线以上，且63日对数收益为正；流动性条件为最近20日中位日成交额至少1000万美元。126日代表半年，63日代表季度，不从本数据中优化窗口。需至少127条完整历史日线。只在收盘使用已知数据，执行仍次日开盘。

企业条件：最近三个可比完整年度净利润及经营现金流均为正；净利润合计不超过经营现金流合计（盈利有现金支持）；最新年度收入不低于前一年度（避免把长期恶化直接当作暂时价格偏离）。最新财年末距判断日不得超过550天，年度末间隔330—400天；财报必须在判断日前已公开。当前SIC仅为审计元数据，不用于历史资格筛选。尚未取得可靠历史企业业务分类，因此候选输出不能宣称正式已验证的企业适用判定。

两组固定实验：A=价格+流动性门控，B=企业+价格+流动性门控。对每个已知池完整保留原股票范围，未通过及证据不足股票目标降至0，释放现金不强制重新分给其他股票。保留原三专家目标、风险缩放与共享资金引擎，正常/双倍成本，共12次。财务缺失不视为负面企业特征，单独记录拒绝原因与覆盖率。禁止以持币收益0证明有效，必须报告暴露及与原方法、等权的差异。

如果候选无改善，如实拒绝；如有改善，先另行固定独立验证协议，再获取未用于这些候选设计的时间/股票数据。适用性判断器在完成确认前输出status=证据不足，candidate_status记录固定条件的通过/不通过，不能把规则通过冒充已验证适用。
