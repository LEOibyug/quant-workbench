# 应收筛选的经济口径核对：不能把比值变化直接当收款质量

本轮重建新增企业交易中使用的全部30个去重“公司—年报”比值，分解应收与收入两部分增长，并保存同份申报的并购相关披露。没有修改资格、阈值或重跑股票收益来选择解释。

## 核实的SPGI合并范围差异

SPGI 2022年同份10-K（0000064040-23-000058，2023-02-10提交）：应收24.94亿美元 vs 上年16.50亿，增长51.15%；收入111.81亿美元 vs 82.97亿，增长34.76%。D=1.12164。

该申报XBRL披露2022年度企业合并以权益支付对价435.36亿美元。取得AnnualReports镜像中的公司2022年报PDF，并读取Overview和资产负债表相关段落：公司于2022-02-28完成IHS Markit合并，2022合并损益自收购日起纳入其经营结果；应收余额24.94/16.50亿美元也与缓存一致。

因此，年度收入分母含收购后部分年度经营，而期末应收是期末合并范围存量；前后年不是恒定经营范围。同申报/同标签核验无法解决这类经济可比性问题。该证据不量化并购对全部比值变化的贡献，也不证明剩余变化来自信用风险或会计操纵。

来源：[SPGI 2022年报镜像](https://www.annualreports.com/HostedData/AnnualReportArchive/s/NYSE_SPGI_2022.pdf)，仅相关段落已读，未声称读完整本文献。PDF SHA与SEC字段来源保存在filing-sources.json和components.json。

## ABT的分母变化

SEC同申报数据表明：2021应收增长1.14%，收入增长24.47%，D约0.81258；2023应收增长5.58%，收入下降8.12%，D约1.14910。比值反映应收和收入的共同变化，不能在没有销售结构/账龄分析的情况下断言收款能力改善或恶化。

## 对“适用企业”的实质要求

若以后使用这个机制，至少需要判断：前后年合并范围是否可比；是否存在重大处置或收购；收入与应收是否对应同一业务；是否有保理、汇率、合同资产重分类等影响。仅当前行业分类和同年报标签不足以得到企业适用标签。

本次还没有实现可靠的自动合并范围判断；并购字段缺失不能当“没有并购”，现金/股权对价也不能直接相加（可能口径重叠）。保存的并购字段仅用于人工核查，不是新交易信号或已验证过滤器。不能在看到失败后删去SPGI再宣称规则通过。

30个比值通过代数恒等式 D=(1+应收增长率)/(1+收入增长率) 的精确重建。复现：`uv run --locked python scripts/audit_receivables_components.py`。总体交易策略或企业适用性目标仍未完成。
