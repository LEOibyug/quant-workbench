# 单股策略适用性判定协议 v1

“适用”必须是**某个冻结策略、某个股票池、某个评价时点**下的统计结论，不能写成股票的永久标签。判断过程如下。

1. **先做数据门槛。** 使用不晚于判断日的数据；价格为正、交易日无缺口，并至少有 505 个共同交易日。股票池必须固定并记录，因为动量、波动率和横截面排名会改变单股结果。缺数据只返回“证据不足”。
2. **冻结策略和费用。** 先登记策略名、参数、调仓频率、费用假设，再读取信号。信号只能在收盘后产生，收益从下一交易日开始计算；换手和期末平仓收费。不得先看这支股票的结果再换参数。
3. **滚动分块。** 将历史切成连续的 126 交易日区块。最后一个区块完全留作确认，前面的区块只用于计算稳定性。每块同时计算策略收益、同段买入持有收益、最大回撤和正收益日比例，核心量是费用后超额收益。
4. **固定通过条件。** 至少 3 个开发区块；开发区块中至少 75% 的超额收益为正；开发区块超额收益均值的同步区块 bootstrap 5% 下界大于 0；最后确认区块超额收益也大于 0。满足时只显示“候选适用（需独立确认）”。任一条件不满足显示“未显示稳定优势”，数据不足显示“证据不足”。阈值不因股票或结果调整。
5. **独立确认。** 候选必须在预先登记的另一时期或另一股票池重复通过，并且经过完整成交、公司行动和多重比较审计后，才可把状态升级为“已验证”。当前仓库没有任何股票达到这个升级条件。

命令示例：

```bash
uv run --locked python scripts/judge_stock_suitability.py \
  --symbol ACN \
  --prices artifacts/research/random-universe-2026-09-21/daily.parquet \
  --strategy fixed_ensemble
```

输出中的 `development` 是历史稳定性诊断，`confirmation` 是未触碰区块；`candidate` 不是未来收益概率。若策略或股票池变化，应重新运行，不能沿用旧结论。
