# 单股适用性协议 v1 撤回与替代方向

上一版本不能作为适用性判断器。CLI 保留兼容，但统一返回“证据不足”，不再产生候选适用标签。

撤回原因：将最高约20%的单股组合权重收益与满仓买入持有比较；收盘信号从同一收盘价开始计收益；没有排除预热期；未核验交易日、公司行动及历史使用情况；三块历史的bootstrap不足以支撑95%置信结论。此前“未触碰确认集”“预先登记”“同步区块bootstrap”的表述过强。ABBV示例不能证明它不适用，也不能证明其他股票适用。

替代判断方法必须针对股票、策略、时点、股票池和现有账户状态：

1. 在判断日以前取得完整行情和已公开财务字段；核验公司行动、共同交易日与流动性。缺失返回证据不足。
2. 冻结一种可解释的资格规则，不能以本股事后盈利为资格。例如企业会计可比组、已公开现金流质量、历史波动及成交容量。条件通过只是候选，不能代表交易有效。
3. 用完整共享资金引擎比较“允许交易该股”与“禁止新增该股”的账户路径，保持初始资产、风控与费用一致。分别考察释放资金留现金和按原规则重分配；原有持仓的退出成本必须计入。核心标签是净收益及风险的边际变化，不是该股账面盈亏。
4. 资格模型只使用已经成熟的历史标签训练；按时间隔离且清除重叠标签，保留未用时期/股票池。筛选器本身必须在冻结后的完整账户中接受检验，不能把逐股消融收益相加。
5. 与同预算、同风控、同交易成本的无筛选组合比较。使用按共同日期抽样、保留股票相关性的区块方法，并对所有尝试的筛选规则进行多重比较处理。区块长度做敏感性分析；历史有效样本不足就拒绝下结论。
6. 只有独立证据支持改善且符合事前风险预算，才给出有期限和范围的适用性结论。否则输出证据不足；有充分负向证据才给出当前条件下不适用。

现有边际标签模型研究已经尝试了步骤3的一部分，但尚未证明能预测适用性；不能把本协议当作实现完成。长期日线结论也不能直接推广到分钟级交易。
