# 生成网络 → 分类器 → 共享资金交易：端到端首版

已实现并训练。训练脚本、约束、固定参数见 [方案](2026-09-18-generated-policy-protocol.md)；完整指标见同名 JSON。

生成器为条件MLP，三种目标为现金、趋势、反转。通过可微单股策略代理收益差训练400步，漂移有界且保留独立噪声。生成6000条训练序列、2000条独立种子测试序列。前64点作为观察，后21步策略净效用决定标签；分类器为12特征逻辑回归。半数样本不经过收益优化，保留无优势与失败样本。没有用真实行情拟合、调参或校准分类器。

生成器能制造策略优势不代表优势能从观察窗口识别：测试准确率48.70%，多数类基线49.15%，log loss 1.0238；几乎不以反转作为最高概率类别，现金偏好明显。选中策略平均未来效用约-0.073%，现金为0%，事后完美选择约2.57%。后者不能交易，只用于说明选择难度。收益代理并非完整的OHLC撮合和资金约束，其预测标签与真实投资效用存在分布差异。

真实评价只读取冻结模型：现有一年20股，63日预热，统一2025-12-01—2026-09-01（不含），初始10万美元、每5日调仓、单股每日10%分批。相同趋势/反转信号由概率混合，经风险缩放后交给共享现金账户执行。

| 执行方式 | 净收益% | 最大回撤% | 双倍成本收益% |
|---|---:|---:|---:|
| 共享资金基础执行 | 3.49 | 3.20 | 2.62 |
| 共享资金成本感知执行 | 2.61 | 2.88 | 2.37 |
| 同区间等权基线 | 9.36 | 9.58 | 9.32 |

结论：训练、推理、策略混合、共享资金、发布与展示的链路已经具备；本版未展现更高收益或优于简单分类基线的能力。较小回撤伴随较少投入，不能单独视为更优选股。未根据这个结果重新调生成器或分类器。真实数据已经参与多轮研究，不称独立样本外；股息、公司行动与日线流动性近似等限制仍在。

本地模型位于 `artifacts/models/generated-policy-v1/`，包含 generator.pt、classifier.joblib、samples.npz、training.json。模型不随Git分发，其他机器运行 README 中训练命令重建。训练采用CPU小网络，不依赖特定GPU。网页研究候选为“生成网络训练分类器 · 策略混合”，展示各股概率；概率不是获利概率。
