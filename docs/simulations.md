# 单股动态模拟与复盘

研究页与展示页都提供「单股交易模拟」。选择该策略/模型支持的股票、日期（结束日不含）、初始资金，点击开始。交易成本沿用冻结版本，包括半价差、滑点、按股佣金、最低佣金与卖出规费。研究模拟保留完整实验的验证/测试流程，不替代用于发布的完整验证。

## 动态曲线

后端每 20 个分钟事件检查一次进度，最多约每 0.5 秒持久化当前前缀；前端约每 0.7 秒请求进度，绘制已计算数据。加载行情和初始化模型时可能暂时没有曲线。历史模拟不代表实时行情或真实下单。

- 股票收盘走势，实际模拟成交价的买入/卖出标记；点击或键盘选择标记查看数量、佣金规费、对应净盈亏。
- 净资产与日内无成本持有基准、可用现金、累计净收益。
- 已实现/浮动盈亏、资金回撤、持仓股数、逐日收益。
- 有模型预测后显示上涨概率、预测收益与成本过滤门槛。
- 成交明细及完整成交、分钟曲线、日收益 CSV。

完成后支持播放/暂停、5/30/120/600 分钟每秒、拖动回放时刻。所有曲线、成交点、盈亏卡片只使用当前回放时刻已知的信息；最终指标与完整导出入口仅在播放到已完成结果的末尾显示。买入点对应盈亏为该笔截至回放时刻的已实现加剩余持仓浮动盈亏，不提前使用未来卖出价。卖出净盈亏按成交数量分摊原买入成本（含佣金），支持分批退出。价差与滑点已包含在成交价格中，不再重复扣除。

横轴使用连续交易分钟，跳过休市；图上时间均为美东。长区间保留桶内极值抽样绘制，分钟数据和导出保持完整。价格图显示最近 400 次成交，表格显示最近 300 次。日收益最后一项在盘中为当日累计值。没有满足条件的交易时，资金曲线保持不变。

## 两页边界

研究页只加载所选冻结实验的数据快照；模拟区间必须位于指定开发、验证或测试阶段内。最终测试必须先完成完整验证，开发期标记样本内；已暴露测试/展示区间的重叠会提示，新的测试模拟也会计入后续实验暴露检查。调整初始资金属于探索性模拟，不修改冻结实验与既有结果。

展示页只加载已发布的策略配置与独立模型权重，从 Alpaca / Massive API 独立获取数据。为规则与模型提供长程历史，下载开始前 45 个日历日的数据；该缓存位于 `data/workspace/`，不会加载研究数据集或结果。发布模型包含可进行样本外模拟的起始日，早于该日期的模拟会被拒绝；旧版本未记录此边界时，明确标记为探索而非样本外验证。每次模拟重新加载离线模型，在线适应不会修改发布权重。

模拟记录与结果按 `research` / `workspace` 分开检索。主目录 SQLite 保存作业元数据，结果位于 `data/simulations/{scope}/`。单次限制 92 个日历日，同时只接受一个未完成的单股模拟；与完整实验共用计算锁。服务重启后未完成作业标记失败。失败前的部分曲线会标为无效完整结果，不提供完整导出。

## HTTP 接口

- `POST /api/{scope}/simulations`：`source_id`、`symbol`、`start`、`end`、`initial_cash`，研究页用 `phase`，展示页用 `provider` / `feed`。
- `GET /api/{scope}/simulations?source_id=...`：当前来源最近 50 条作业。
- `GET /api/{scope}/simulations/{id}`：状态/进度。
- `GET /api/{scope}/simulations/{id}/result`：当前已知完整前缀或最终结果。
- `GET /api/{scope}/simulations/{id}/export/{kind}`：完成后的 `trades`、`market_curve`、`daily_returns`。

不同 scope 访问同一 ID 返回 404。所有接口只供本机使用；页面隔离不是多用户权限系统。
