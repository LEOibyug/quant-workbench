# 多尺度在线时序模型 v3

本文保留线性/RBF/MLP基线说明；研究页当前默认的卷积+双尺度GRU与CUDA/MPS/CPU自适应见[序列模型](sequence-model.md)。

分钟级行情，每分钟决策。模型预测未来 h 分钟的上涨概率及收盘收益，h 可选1、5、15；不是实盘逐笔高频系统。模型只过滤规则入场，不能否决止损、止盈、超时与收盘清仓。

## 模型结构

v3研究页原默认使用 `architecture=mlp`、k=30、h=5：两个独立的全连接网络，各含64、32个tanh隐藏单元，分别分类涨跌与回归收益。Adam优化器、L2系数0.01，默认学习率0.001；在线阶段每个已成熟样本进行一次更新。不是RNN：记忆来自有界行情历史、持续更新的权重/优化器状态和最近已成熟的预测误差。

可对照 `linear`（原来的逻辑分类与Huber回归）及 `rbf`（加入默认64个固定随机傅里叶特征近似RBF核，再使用在线线性双头）。两者保持原来8个短程特征；RBF与MLP额外使用长程特征。所有版本不依赖大语言模型。

MLP共20维输入：

- 短程8维：1、k/4、k/2、k−1分钟收益，窗口波动率、相对成交量、当分钟振幅和均价偏离。
- 长程6维：最近390/1950/7800根交易分钟的累计日内对数收益、390/1950根分钟的波动率、相对390根分钟均量。约相当于1/5/20个完整交易日，半日市会有差异。
- 反馈6维：最近已成熟的上涨预测概率、真实涨跌标签、预测收益、实际收益、实际减预测的误差，以及反馈是否可用。概率与标签减0.5；收益/误差除100bps；截断到[-10,10]。

所有决策前历史允许读取，但不强行把全部历史逐条塞进网络。训练/运行共用相同长程特征定义，日内收益链排除隔夜跳空与跨日拆股跳变，因此**不包含隔夜动量、复权日线趋势或公司行动总回报**。未来若引入这些信息，应另接复权数据。

## 离线训练与反馈生成

MLP训练区间内部再按时间划分约60%/40%：

1. 前60%初始化双头网络及标准化器；该阶段反馈输入为0。
2. 清除标签跨越分界时刻的样本。固定这个早期模型，在后40%按时间顺序生成预测；仅当旧预测目标时间到达，才将它的预测、GT及误差用于当前输入。
3. 使用后40%的特征和目标继续训练网络。反馈教师未见后40%的标签，避免把同一样本拟合后的误差冒充真实预测误差。

反馈教师与最终网络有分布差异，效果必须通过验证检验；本实现没有声称反馈必然改善精度。MLP回归采用平方误差，目标以百分比缩放并截断到±10%；线性/RBF回归仍用Huber损失。标准化只拟合训练数据，运行期冻结。元数据记录结构、输入维度、样本数量、目标末时刻、版本。

## 运行时严格时间顺序

标签为 `close[t+h] / close[t] - 1`，涨跌标签可增加 `min_return_bps`。h=1时上一时刻GT在下一分钟揭晓；h=5/15时对应GT必须延迟5/15分钟，期间仍每分钟预测。每只股票各自保存待成熟队列、模型权重与优化器状态。

每根已结束分钟：

1. 揭晓队列中已经到期的标签，用预测当时保存的输出计分。
2. 将最近已成熟预测、GT及误差存为反馈；若`adapt=true`，用该旧样本**当时保存的输入**更新双头，不把新GT插回旧输入。
3. 更新短/长程历史，构造当前特征及反馈，预测未来h分钟，并将当前输入和预测放入待成熟队列。

第k根开始生成内部学习预测；第k+h根才可能第一次监督更新。前2k根运行观察全部禁止模型交易且不对外给出概率。从2k+1开始规则与模型共同决定入场。若k<h，适应区间内成熟标签较少，这由所选跨度决定。

阶段开始前可读取数据集中所有早于阶段开始的行情准备长程背景，不更新权重、不消耗2k适应期。运行期短窗口跨日或遇缺口重建，待成熟标签和反馈清空；跨日保留学习权重、长程背景和累计运行计数，不构造隔夜标签。后来每个交易日重建k窗口，不重复整段2k适应期。

验证与最终测试分别重新加载同一个离线模型。最终测试可以读取验证期间已经发生的行情作为历史背景，但不继承验证期间的在线权重。这是在线自适应测试，不是权重完全冻结的测试；可将`adapt=false`作为对照。

## 成本与评分

成本过滤要求：`预测h分钟收益bps > 往返成本bps × cost_multiplier + min_edge_bps`，默认1.5倍加1bps；上涨概率默认至少0.55。成本由当前已结束分钟价格、成交量、现金和增强策略的风险股数上限估计，计入价差、双边滑点/佣金和卖出规费。实际成交在下一分钟开盘近似执行并重新计算费用。分笔最低佣金、跳空及真实盘口会造成估计偏差。

模型预测的是收盘到收盘收益，实际交易是下一分钟入场并按规则退出，两者收益口径不同；h不是持仓保证。策略目标距离覆盖成本也不等于预测盈利。

统计包含准确率、Brier、log loss、收益MAE及固定训练涨跌比例/零收益基线，先评价后更新，包含适应期预测。审计仅保留最近500条，累计统计覆盖全段。

## 存储与兼容性

Mac/Linux CPU可运行，当前scikit-learn实现不会调用NVIDIA GPU。此规模优先验证成本后的实际效果；GPU版需另外迁移训练后端。

joblib离线产物不包含运行记忆；旧线性模型加载时补默认配置。`checkpoint_state()`单独保存在线权重、优化器、待成熟队列、短长程历史及误差反馈，不能替代新阶段的离线初始化。只加载可信本地模型；依赖版本升级建议重新训练。
