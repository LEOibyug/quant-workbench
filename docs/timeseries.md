# 离线初始化与在线时序学习

本模块使用价格、成交量和已揭晓的下一分钟涨跌标签训练，不调用大语言模型或网络服务。
模型为 `SGDClassifier(loss="log_loss")` 加离线训练期拟合的 `StandardScaler`，
通过 `partial_fit` 连续更新权重。它是可在线学习的线性分类器基线，不是 RNN 或深度网络。

## 时间顺序

1. 先仅用较老的训练区间初始化分类器和标准化参数，按时间顺序分批训练；不随机拆分验证。
2. 部署运行的前 k 个完整分钟收集窗口，第 k 个分钟开始记录内部学习诊断概率，不向交易或展示接口提供预测。
3. 第 k+1 个分钟结束后，上一预测的真实标签首次揭晓；先评价上一预测，再更新权重。
4. 前 2k 个已观察分钟全部禁止模型交易，对外概率为 null，在 k 到 2k 区间进行监督适应。
5. 从第 2k+1 个分钟开始，继续先更新上一成熟标签，再预测下一分钟；规则买入信号和概率门槛共同决定交易。

每个分钟都必须调用 `predict`，包括没有规则信号的分钟。引擎不能仅在准备买入时调用。
输入 `context` 为股票、决策时间、截至当前的行情；预测不读取还未结束的下一分钟。
标签默认 `close[t+1] > close[t]`，可用 `min_return_bps` 增加最低收益阈值。
下一分钟收盘涨跌并不等同于下一开盘实际成交的利润，回测仍单独计算价差、滑点和手续费。

## 窗口和股票隔离

窗口宽度 k 默认 30，范围 5—120。特征包含 1、k/4、k/2、k-1 分钟相对收益、
窗口收益波动率、相对成交量、当分钟价格区间和均价偏离。
标准化参数只在较老训练数据拟合，运行期冻结；标准化特征截断到 [-10,10] 以限制异常值影响。

每只股票从相同的离线模型复制独立在线权重，避免按股票顺序回测时把某股票未来期间
已经学到的标签用于另一股票较早的预测。新交易日或缺失分钟会清除历史窗口和待揭晓标签，
重新收集 k 根连续分钟；保留已学习权重和本次运行累计计数，不跨夜构造标签。
不同验证／测试阶段需要重新加载离线模型并从零开始在线状态。

## 配置与结果

`TimeSeriesConfig` 包含 `enabled`、`k`、固定为 1 的 `horizon`、`probability_threshold`、
`min_training_samples`、`max_iter`（离线训练轮数，默认 5，最多 20）、
`min_return_bps`、`online_learning_rate`（默认 0.001）和 `adapt`。
关闭 `adapt` 可比较同一离线模型不更新的表现；前 2k 禁交易约束仍保留。

`train_model(frame, config)` 只接收训练数据。尾部没有下一分钟标签的行丢弃，不跨交易日或缺口。
默认至少 200 个有效样本，正负类各至少 20 条，最多 100,000 个样本按确定时间步长抽样。
`TimeSeriesModel.predict(context)` 返回 `allow_entry/probability/reason`，有效观察另有
`observed_count/warmup/updated`。模型只能过滤规则买入，不能覆盖退出和风险控制。

`stats` 包含预测、在线更新、否决、预热次数及逐股统计；`accuracy` 使用预测当时记录的概率
与后来揭晓的标签比较，包含预热期间，门槛 0.5，与交易概率门槛分开。
这属于逐步前瞻评价，不能拿在线更新后的模型重新预测过去来计算准确率。
同时记录 Brier 分数和对数损失（越低越好），并比较固定离线训练涨跌比例预测器的
准确率、Brier 和对数损失。基线概率只来自离线训练标签比例，不利用测试标签重新选择多数类。
审计只保留最近 500 条，完整长期指标使用累计统计。元数据记录离线训练边界和依赖版本。

在线测试允许模型使用测试期间已经过去的标签，但不能用未来标签或测试结果调参。
此结果应明确标记为在线自适应评价，与权重完全固定的离线样本外测试区分。

## 本地部署

运行完全使用 CPU，兼容 Mac 和 Linux；不会自动调用 NVIDIA GPU。
joblib 只保存离线初始化模型，序列化时清除在线状态、审计和统计；每次运行各自适应。
需要单独保存在线运行检查点时使用 `model.checkpoint_state()`，它返回与原对象隔离的
可序列化字典，包含逐股适应后的权重、窗口、待揭晓标签、计数、统计与审计。
该字典必须保存到独立的运行检查点路径，不能替代离线初始化模型或用于新的测试阶段。
只加载系统自己生成的可信本地文件，不允许任意上传模型直接反序列化。
升级 scikit-learn 版本建议重新训练。实时预测和回测收益都需要真实行情验证，
不能从合成数据或本模块实现本身推断实际获利能力。

## v2：上涨概率 + 收益幅度与成本约束

模型现在包含两个在线输出：逻辑分类器估计下一分钟上涨概率，Huber损失的SGD回归器估计下一分钟收盘收益（bps）。两个模型共用开发期拟合的特征标准化，按相同时间顺序离线训练；回归目标用百分比缩放并截断到±10%，降低极端数值对训练的破坏。它们各自为线性模型，并非深度循环网络。

下一分钟收盘后，先评价此前的预测，再使用成熟标签更新两个模型。回归误差以未截断的实际收益计算MAE，并与恒定预测0的基线比较。每股各自保留模型状态；前2k周期均不对外提供预测。

当`cost_aware=true`，规则与概率通过后还要求：

```
预测下一分钟收益_bps > 估计往返成本_bps × cost_multiplier + min_edge_bps
```

默认研究界面启用此约束，倍数1.5、额外优势1bps。后端旧配置默认关闭以兼容旧实验。往返成本按最新已结束分钟价格、成交量参与率、可用资金估计可买股数，计入双边半价差、滑点、双边最低/按股佣金和卖出规费。实际成交再按下一分钟价格与实际分笔计算，预估不能替代最终扣费。

成本参数是外部市场/券商假设，不可调低费用来“优化收益”；可在开发/验证段选择的是保守倍数、净优势和模型门槛。1.5倍、2倍费用属于压力情景，始终完整重跑成交与费用，非简单给利润加减常量。成本预估假定一次买入和一次卖出，流动性不足引起的分笔最低佣金可能更高。

回归模型预测下一分钟收盘变化，规则可能持有多分钟，因此此过滤是保守的一步预测策略，不是对整个持仓期限的利润预测。若过滤后没有交易，应报告无交易，而非凭测试结果放宽门槛。未来如预测多分钟目标，必须将在线标签成熟时间同步推迟。

旧版本离线模型加载时补充成本配置默认值；缺少收益回归器的旧模型仍可执行概率过滤，不能伪造收益预测。要使用成本收益过滤必须重新创建实验、训练双输出模型。展示页仍只接收发布的策略配置和独立模型文件，不接收研究数据或报告。
