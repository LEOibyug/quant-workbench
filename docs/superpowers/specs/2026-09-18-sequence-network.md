# 双尺度时序网络与状态规则

已授权范围：实现真实序列网络、改进规则、保持分钟因果性、历史可见性与隔离；本地CPU/Linux CUDA兼容，继续维护GitHub。

模型使用7维逐分钟OHLCV/日内时间token，k=30；短支路因果卷积(32通道)+双层GRU(64)+注意力汇聚，长支路最近78个已完成5分钟token的GRU(32)+注意力汇聚。并入6维长历史背景与6维已成熟预测/GT/误差，输出上涨概率和h分钟收益。h仍为1/5/15。GRU在窗口内建模序列；每次用当前权重重算窗口，避免在线更新后沿用陈旧hidden state。跨窗口记忆来自长期序列、历史背景、回放和学习权重。

仅训练期拟合归一化，早期60%初始化反馈教师、后40%用教师的已成熟预测生成反馈训练最终网络；跨边界标签清除。线上16个成熟样本触发一次AdamW更新，512个近期成熟样本回放、梯度裁剪1.0、学习率3e-5；离线3e-4。前2k观察禁交易，日内缺口清除短窗口与待成熟标签，长背景保留。离线产物保存CPU状态字典、版本；CUDA由运行机器选择。

新规则：趋势回调与状态组合。用最近60分钟慢趋势/效率区分趋势、震荡、下跌；上行趋势只在短期回调后的恢复确认时入场，震荡只在VWAP统计偏离且止跌时回归，下跌/不明确时持币。保留ATR风险、成本、交易次数、冷却、尾盘清仓；新规则利润空间还需覆盖风险距离，过滤收益风险比不足的信号。

评估固定候选集合，旧规则为对照，新规则比较两组明确风险/持仓参数和相同规则+GRU。验证同时看前后半区间表现，最终测试仅在选择冻结后读取。预定新SIP范围2025-11-01至2026-02-01；训练至2025-12-16，验证至2026-01-01，2026年1月最终测试。先验证供应商实际覆盖，不填补缺失分钟。结果不自动发布实盘。
